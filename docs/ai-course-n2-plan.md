# AI日本語コース N2化 監査＋設計（Phase N2-A）

> 目的: 会話力を中心に、JLPT **N2合格水準**（語彙・文法・読解・聴解・会話運用）を「実際に使える形」で伸ばす。
> 方針: 会話コアとN2試験対策を分けすぎず「理解→聞く→使う→読解で見抜く→試験で選ぶ→会話で使う」の循環にする。
> **合格保証はしない**（「N2合格水準を目指す」と表現）。公式JLPT問題は無断転載せず独自作成、AI生成教材は人間レビュー前提。
> 現段階は**監査・構造・試作のみ**。教材本文は捏造・大量自動生成しない。

---

## 1. 現在のコースでN2合格水準に足りないもの（結論）

現行60ミッションの目標表現を精査した結果、**本コースは実質「N4→N3の会話基礎」**であり、**N2そのものはほぼ未カバー**。
- 例（実データ）: 〜といいます / 〜に住んでいます / 〜たことがあります / 〜ようになりました / 〜てもいいですか / 〜と思います / 〜かもしれません … いずれもN5〜N3。
- **純粋なN2文法（〜わけではない・〜ものの・〜ざるを得ない・〜に応じて・〜をめぐって・〜だけに 等）＝ 0 件。**
- N2語彙（約6,000語規模）・N2読解（中長文・情報検索）・N2聴解（自然速度・意図理解）の**専用教材は存在しない。**

→ **不足しているもの**: ①N2文法 約80〜120項目 ②N2語彙 段階配列 ③N2聴解（自然速度音声＋設問）④N2読解（中長文＋設問）⑤JLPT形式演習 ⑥模擬試験 ⑦弱点ダッシュボード。

## 2. 60ミッションのN2カバレッジ（監査）

分類（`src/lib/aiLesson/course/courseN2.ts` に固定・人間レビュー可能）:

| 区分 | 意味 | 件数（概算） |
|---|---|---|
| 会話基礎(daily) | N4〜N5の会話土台 | 約 44 |
| N3相当 | N2への足場 | 約 13 |
| N3〜N2橋渡し(n2bridge) | どちらかというと/〜ことになっています/〜させていただきます 等 | 約 3 |
| **純N2文法** | — | **0** |

判定サマリ:
- **N2に有効**: ごく少数（敬語・改まり表現の一部）。
- **N3相当**: 変化・推測・比較の週（〜ようです/はずです/ほど〜ない/に比べて 等）。
- **日常会話基礎**: 大半（自己紹介・許可依頼・困りごと・意見・交流）。
- **N2補強が必要 / 別教材が必要**: N2文法・語彙・読解・聴解は**別トラックが必須**。
- **重複・不足**: 各週の5番目「総合」は良い設計。不足は明確にN2知識系。

**結論: 現行60でN2全範囲をカバーしたことにしない。会話コア(60)＋N2トラック群の並列構造にする。**

## 3. 会話コアとN2トラックの統合設計（並列構造）

```
会話コア60ミッション（既存・N4→N3会話）  ← すでに実装済み
        │  各章に「会話目標」＋「N2目標」を併記（Phase N2-A・実装済み）
        ▼
┌─────────────┬─────────────┬─────────────┬─────────────┐
│ N2文法トラック │ N2語彙トラック │ N2聴解トラック │ N2読解トラック │  ← 新規（固定教材・人間レビュー）
└─────────────┴─────────────┴─────────────┴─────────────┘
        ▼
   JLPT形式演習（章末・週末） → 弱点ダッシュボード → N2模擬試験
```

**循環（各N2文法・語彙で共通）**: 意味を見る → 中国語で理解 → 接続確認 → 例文を読む → 音声で聞く → 意味を選ぶ → 自分の内容へ置換 → **音声会話で使う** → 別場面で使う → 後日復習 → JLPT形式で解く。
- **「選択問題で正解＝使える/定着」とは判定しない**（会話での自力使用・後日想起を重視）。
- 聴解で聞いた表現を、そのまま会話練習へ再利用（聞いて分かる→説明できる→自分で使う）。

## 4〜8. 各トラックのデータ構造（設計・未実装。教材本文は未生成）

> すべて**追加的・AIコース専用・固定教材（人間レビュー）**。DB不要（静的データ）で開始でき、規模が大きくなれば専用テーブルを検討（その場合は migration 案を別途・本番未適用）。

**N2文法（grammarId 単位）**: `id / expression / reading / meaning / meaningZh / connection(接続) / nuance / scenes[] / convExample / readingExample / listeningRef / similar[] / difference / commonMistakes[] / selfSubstitution / quiz{ stem, choices[], answer, whyCorrect, whyWrong[] } / level(N2/N3) / reviewedBy(人間) / sourceOriginal:true`

**N2語彙（vocabId）**: `kanji / reading / meaningZh / pos(品詞) / scenes[] / collocations[] / synonyms[] / antonyms[] / convExample / readingExample / listeningRef / usageQuiz / paraphraseQuiz / multiSense[]（見送る＝諦める/送り出す 等）`

**N2聴解（listeningId）**: `skillType(課題理解/ポイント/概要/即時応答/統合) / scene / speakers[] / audioRef(固定/事前生成) / question / choices[] / answer / evidenceUtterance / trickyExpressions[] / explanationZh / scriptJa / speed(通常/遅め) / subtitle(on/off) / linkedGrammarIds[] / linkedConvMissionId`

**N2読解（readingId）**: `type(日常/職場/メール/お知らせ/広告/体験談/意見文/比較/説明/イベント) / bodyJa / questions[]{ q, choices, answer, why } / keyPoints / authorIntent / paraphrase / requiredInfo / speakBackPrompt(自分の言葉で話す導線)`

**JLPT形式演習（quizItem）**: `format(漢字読み/語形成/文脈語彙/言い換え/用法/文法選択/文の並べ替え/文章文法/短文読解/情報検索/聴解) / stem / choices[] / answer / whyCorrect / whyWrong[] / sourceOriginal:true(無断転載しない) / linkedItemId(復習送り)`

## 9. N2能力マップ（実装済み・正直表示）

`buildN2Map(progress)` を実装（`courseN2.ts`）。6軸=語彙/文法/読解/聴解/**会話で使用**/**復習定着**。
- **会話・復習軸**は既存進捗から算出（N3以上の表現の自力使用数・復習成功数）。
- **語彙/文法/読解/聴解軸は「準備中」**（専用トラック未実装のため。架空達成を出さない）。
- **合格率・合格可能性は一切表示しない**（テストで `passRate`/`passProbability` 不在を担保）。
- 推奨表示: 学習済み文法数 / 自力で使えた文法数 / 後日理解できた数 / 苦手な問題形式 / 次に重点的に学ぶ分野。

## 10. 模擬試験（設計のみ・未実装）

`section(言語知識/読解/聴解) / timeLimit / pauseResumeRule / scoring(分野別) / result{ byArea } / wrongReviewLink / historyCompare`。
- 段階実装: まず「章末の短い独自演習」→「週末確認テスト」→「分野別ミニ模試」→「フル模試」。
- **参考表示のみ**（合格可能性の断定はしない）。

## 11. 学習時間の現実性（初期レベル別ロードマップ）

現3か月コース単独で初級者がN2到達、とは**断定しない**。管理者が数値調整可能にする。
- **N2学習経験あり / N3合格相当**: 会話コア＋N2総合対策で **約3〜6か月** を目安。
- **N3基礎がある**: N2文法・聴解・読解を追加して **約6か月〜**。
- **初級から**: まずN3基礎を固めてからN2へ（会話コアはそのまま活用）。

## 12. 必要教材数の概算（人間レビュー工数の目安）

| トラック | 項目数(目安) | 1項目の要素 | レビュー観点 |

## 13. 固定音声・APIコスト方針

- 聴解は**Realtime都度生成をしない**。**事前生成音声（TTS一括生成）を静的ファイル化**して配信（`public/ai-n2-audio/…`）。閲覧・再生でAPIを呼ばない。
- 会話（Realtime）は従来どおり上限管理。予習・N2教材の閲覧・問題演習は**API不使用**（Phase N2-Aの予習と同じ設計）。
- 速度調整（通常/遅め）は事前生成の2バージョン or クライアント再生速度で対応。

## 14. 段階実装ロードマップ

- **Phase N2-A（今回・実装/反映済み）**: 60ミッションのN2監査・N2能力マップ・目標再定義・**会話目標＋N2目標の併記**・データ構造設計。
- **Phase N2-B**: N2文法トラック（固定例文・中国語解説・独自テキスト問題・復習連携）。まず高頻度N2文法 20〜30 から。
- **Phase N2-C**: N2聴解（事前生成音声・字幕on/off・設問解説・会話への再利用）。
- **Phase N2-D**: 読解・語彙・週末確認テスト・弱点ダッシュボード。
- **Phase N2-E**: 模擬試験・分野別結果・参考判定。

## 15. 本番公開前に必要な操作（N2分）
1. N2文法/聴解/読解/語彙の**教材を人間レビューで確定**（AI下書き→承認）。
2. 事前生成音声を `public/` に配置し配信確認。
3. 独自問題であることの最終チェック（無断転載なし）。
4. 初期レベル別ロードマップの数値をCEOが設定。
5. staging で会話⇄N2の循環E2E → 本番反映（別途）。

## 16. 人間レビューが必要な項目（要CEO/専門確認）
- `MISSION_N2_LEVEL` の分類（N4/N3/橋渡し）の妥当性。
- N2文法説明・中国語訳・接続・ニュアンスの正確性。
- 独自問題の難易度・選択肢・正誤理由。
- 聴解音声の自然さ・速度・聞き取り難易度。
- 初期レベル別の推奨期間（合格保証にならない表現）。
