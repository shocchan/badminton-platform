  （運営者が現状維持の方針と決めているため）

### 事業B：AI日本語会話コース（中国語話者向け）

在日の中国語話者（N3〜N2レベル、「読めるのに話せない」人）向け。
Webアプリ + AI音声会話 + 人間コーチ。商品は3つ：

| 商品 | 価格 | 内容 |
|---|---|---|
| AI体験パス | **¥600** | 開始から**60分間**（実時間）。AI音声会話3回、教材・冒険マップ使い放題 |
| 1か月 AI自学プラン | **¥2,980 / 30日** | 教材使い放題、AI音声会話 月10回、テキスト会話 1日8回 |

技術的な実体：
- React + Cloudflare Pages + Supabase。Stripe決済（银行卡・支付宝・微信支付に対応）
- AI音声会話は OpenAI Realtime API。会話後に自動でレポート（できたこと・訂正・自然な言い方）
- 間隔反復（忘れかけた頃に同じ表現を再出題）が学習設計の中心

集客チャネル：小紅書（XHS）、WeChat。運営者のXHSフォロワーは約5,600人。

## 4. 私（Claude）の結論

### 結論の1行

**強い商品を安く売り、弱い商品を前に出している。**

### 根拠

**(a) AIコースの月額プランは、勝てない土俵にいる**

¥2,980/月のAI自学プランが提供する価値（AI会話練習・シーン練習）は、
中国のAI日本語アプリが**年間328元**で提供しているものと役割が重なる。
相手は1,800万ユーザー、5万シーン、24時間対応。
機能量でも価格でも勝ち目がない。

**(b) 6か月コースは、勝てる土俵にいるのに安すぎる**

24回の1対1レッスンを日本人ネイティブが提供して198元／時は、
中国市場の相場（300〜800元）の下限を下回る。
早道日语の外教550元／課時と比べれば**半額以下**。
かつ「日本に住んでいる中国語話者の生活を知っている日本人」という
代替の効きにくい立ち位置がある。

**(c) LPの並び順が、その強みを打ち消している**

コーチ紹介が価格表より**後ろ**（9番目 vs 6番目）。
読む人は「この商品にしかないもの」を見る前に値段を見るので、
AIアプリと横並びで価格比較される。

**(d) 大会は、種目の選び方だけで平均が上がる余地がある**

ダブルス7.5人 / シングルス1.8人 / 混合ダブルス0人。
集客を増やさなくても、開催種目の配分を変えるだけで平均申込が上がる。

**(e) 大会は、やった事実が資産になっていない**

8回開催して結果公開は3回。ランキングは0行。
競合は5年分の年間ランキングを積み上げている。
ランキングは記録ではなく「来年も出る理由」＝リピートの動機。
現状のリピート率18%はこれと無関係ではないと考えている。

### 提案している着手順

1. 【今週・実装不要】混合ダブルス単独をやめ、ダブルス中心に組み直す
2. 【今週・素材あり】第4〜8回の結果を公開し、通年ランキングを始める
3. 【今週・実装不要】AIコースLPでコーチ紹介を価格表の前へ移す
4. 【集客より先】小紅書・WeChat・広告のリンクにUTMを付ける
5. 【今月】大会のレベルを2段階に割る／初参加特典を申込ボタン付近に置く
6. 【今月】大会の申込を先払い既定にする
7. 【今月】学習レポートに「この一文を紹介してよいですか」の許諾を付け、誇張なしで声を集める
8. 【経営判断】6か月コースの値上げ／月額プランの位置づけ／体験の時間設計

## 5. 私が間違っているかもしれない点

セカンドオピニオンで特に検証してほしい箇所です。

1. **サンプルサイズが極端に小さい。**
   種目別の差（7.5 vs 1.8 vs 0.0）は、大会数がそれぞれ2・4・2回しかない。
   曜日・時間帯・告知の量・季節が交絡している可能性を排除できていない。
   「ダブルスが強い」ではなく「8/13の1回がたまたま当たった」だけかもしれない。

2. **元／円の換算レートは仮定。**
   1元≈20円で計算しているが、レートが動けば「相場の下限の2/3」という結論の強さは変わる。

3. **中国市場の価格情報はWeb記事由来で、一次情報ではない。**
   実際の成約価格ではなく、広告的な提示価格の可能性がある。

4. **「値上げすべき」は需要が存在する前提。**
   現設計で0件売れている状態で値上げを勧めるのは、順序として危ういかもしれない。
   先に「売れること」を確認すべきという反論はあり得る。

5. **LPの並べ替えの効果を私は測っていない。**
   「コーチを前に出せば効く」は仮説であって、実証ではない。

6. **大会とAIコースを同じドメインで運営している影響を評価していない。**
   日本人向け大会と中国語話者向け語学商品が同居することの是非は、今回踏み込んでいない。

7. **運営者は1人で本業もある。**
   提案8項目は多すぎるかもしれない。1つに絞るならどれかという観点は入れていない。
