# AI日本語伴走コース プラットフォームビジョン（Phase 2C+）

## 総合日本語学習プラットフォームとしての姿
単なるAI会話・単語帳・文法問題集ではなく、中国語母語の成人学習者が一つのサービス内で
「今日やることを確認→画像で言葉を覚える→読み・意味を理解→使い方としくみを確認→タップ問題で確認→
覚えた/まだ不安を記録→苦手だけ復習→AI会話で使う→人間レッスンで深める→成長を見る」までつながる。

## 中核学習ループ
見る→理解する→選ぶ→思い出す→使う→間違える→復習する→別の場面で使う→定着する

## 役割分担（§2・§22）
| 機能 | 役割 |
|---|---|
| 学習ホーム | 今日何をすればよいかを一瞬で示す（第一CTA一つ） |
| ことば図鑑 | 画像と一緒に語彙を理解・記憶状態の記録・関連語（認識・理解） |
| 日本語のしくみ | 活用・助詞・接続・語順・正しい形の選択（構造確認） |
| AI会話 | 想起・発話・言い直し・別場面での実使用 |
| 人間レッスン | 誤解と癖の修正・本人の生活/仕事/目標への接続 |
| 学習記録 | 覚えた/不安/確認済み/会話で使えた/復習予定の可視化 |

選択問題中心でもアウトプットが不足しない設計: 想起・発話はAI会話・PREP・人間レッスンが担当。
語彙詳細・単元結果に「AI会話で使ってみる」導線を持つ（現状は既存会話ホームへの遷移。
targetExpressions連携は既存会話が受け取り未対応のため候補データのみ・§34）。

## 人間レッスン接続（§35）
講師が将来確認できる候補: まだ不安な語／self_knownだが誤答した語／助詞誤答／7日後確認予定／目標語彙。
Repository interfaceは実装済み（getReviewItemIds・getStats・verifiedState）。管理画面はPhase 2D以降。

## 個人専用語彙（§36・将来）
LearnerVocabularyGoal（learnerId/itemId/customExpression/reason/priority/reviewStatus/addedBy）。
学習者の自由追加は品質・重複の問題があるため実装しない。追加希望→既存Item検索→重複確認→
講師/AI下書き→人間レビュー→approvedのフローで将来対応（§37）。DB適用なし。
