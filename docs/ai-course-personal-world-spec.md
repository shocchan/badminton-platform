# 本人が主人公の学習世界 仕様書（Group G・未コミット承認待ち）

基準: `c627378` ／ 実装なし・設計のみ。中心思想: **「問題を解いた記録」ではなく「日本語で生きた6か月の記録」**。

## 1. 世界観と役割
- **本人=主人公**（学ぶ・話す・間違える・言い直す・現実で使う・思い出を残す）。先生を主人公にしない
- **翔子先生**=安心・案内・復習・振り返り・エラー時／**悠斗先生**=会話・挑戦・応援・完了・実生活への送り出し／**安田コーチ**=現実の人間・方向決定・重要場面指導（AIと混同させない=実装済みの役割表示を踏襲）
- **依存防止**: 「私だけがあなたを理解」「毎日必ず会いに来て」等の文言禁止。AIは現実の人との会話・コーチ相談・休息を肯定する（既存トーンガイドに追記）

## 2. わたしの日本語ノート（1セッション=1ページ）
- **データは全て実在**: 日付・場面(mission.titleJa/Zh)・使えた表現(targetUsed/usage)・言い直した表現(report.corrections+retry結果)・先生の一言（**決定的テンプレ**: usage/kind別に4種×2先生=8種をローテ・LLM不使用=費用ゼロ・誤生成ゼロ）・次の復習日(nextReviewAt)・学習時間(durationSeconds)
- 学習していない日はページを作らない（偽造禁止）。「間違いノート」に見せない=できたこと先頭・修正は折り畳み
- **MVP**: 既存sessions+reportの読み取りのみ（DB変更なし）。学習記録の「わたしの表現」の隣に「ノート」タブ
- 空状態: 「最初の会話を終えると、ここに最初のページができます」／ja/zh／モバイル1カラム

## 3. 思い出アルバム（節目のみ）
- 節目候補: 初会話完了・初自力使用・初言い直し・初翌日復習・1週間・各月末・3か月中間・6か月修了（**全て既存データから決定的判定可能**=sessions/progress/週数）
- カード: タイトル・日付・本人アバター（無ければイニシャル円）・達成事実・使えた表現1つ・次の目標
- 禁止: 架空達成・毎日記念日化・紙吹雪・他人比較・同意なき外部公開
- **MVP**: 判定は表示時に都度計算（保存なし=DB変更なし）。Phase Avatar 4で保存型へ

## 4. 月次ストーリー / 6か月修了アルバム
- 月次: **決定的テンプレ優先**（今月の会話数・最多カテゴリ・自力使用になった表現列挙・来月の週テーマ）。LLM要約はP3（費用$0.002/月・誤断定リスク・コーチ確認前提の設計のみ）
- 修了アルバム: Webページ（印刷CSS対応）を将来形とし、PDF/共有リンクは別フェーズ

## 5. デザイン原則（成人向け）
ノート・アルバムの手触り（紙色=既存ivory系・余白・細罫線）／学習成果が主役・キャラは補助／星・コイン・宝箱・ランク・バトル禁止／演出は400ms以内・reduced-motion対応

## 6. 成功指標
ノート閲覧率・完了後の記録閲覧率・復帰率・「自分だけの日本語の物語になっていると感じるか」「一人で勉強している感じが減ったか」「6か月後も残しておきたいか」（修了時アンケート・当面WeChat運用）
