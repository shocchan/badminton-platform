## 4. 分類サマリー

**既に十分良い / 競合水準**: 今日のCTA・3分完了・SRS・会話終了制御・訂正抑制・エラー/フォールバック・ja/zh・費用ガード・セッション復旧。
**競合に劣る**: ①通知/リマインド不在（Duolingo比）②N2教材の深さ10/180（Bunpro/LingoDeer比・教材制作の問題でありアプリ構造は先行）③streak途切れ後の復帰文言。
**独自の強み**: 言い直しフロー／AI+人間の期間設計／中国語母語者特化（訳・ふりがな・commonMistakes）／実発話ベースのレポート・Before/After／端末間復旧。
**独自価値が弱く見えている**: **人間コーチがアプリ内でほぼ不可視**（設定の問い合わせのみ）。「AIが毎日支え、人が進む方向を決める」が画面から読み取れない。
**UX摩擦**: 復習理由の説明なし／成長画面にコーチの一言枠なし／streak=0の空気。
**教育設計弱点**: N2詳細教材の量（人間作業）／転用（別場面）練習の明示不足。
**技術リスク**: 旧タブ同時送信（被害は8ターン上限で限定・device token案はDB変更のため設計のみ）／LLM応答品質のばらつき（ガードで下限は担保）。
**セキュリティ**: JWT+所有+in_progress確認済み・Secretはサーバーのみ・PII送信なし。追加リスクなし。
**コスト**: テキスト$0.004/会話・音声は既存上限管理。閲覧でAPI起動ゼロを318テストの前提で維持。

## 5. 優先順位

**P0（今すぐ）**: なし（学習不能・誤課金・データ破損級は現存しない。✏️null修正済み）。
**P1**: ①人間コーチの可視化（ホーム/成長にコーチ枠＋WeChat相談導線の意味づけ）②復習の「なぜ今」1行理由③streak途切れ復帰文言④状態別ホームCTA文言⑤P0イラスト3種の受け入れ（画像待ち）。
**P2**: ⑥N2カテゴリ73件レビュー反映（マップ編集のみ）⑦交流会接続の設計⑧転用練習の可視化⑨PWA/WeChatリマインド⑩音声言い直し。
**P3**: 中国語母語者専用の誤用検出（同形語・助詞）／コーチ用進捗ダッシュボード／通知基盤。

## 6. 実装しない方がいいもの

- ランキング・他人比較（心理的安全性と矛盾）／ハート・ライフ制（罰ゲーム化）／紙吹雪級の祝福演出
- アプリ内チャットコミュニティ（HelloTalk模倣・運営コスト過大・kawabado実交流で代替）
- ストリークフリーズ課金等のダークパターン／連続日数の喪失恐怖演出
- N2の180項目一斉詳細化をAI生成で埋めること（品質保証不能・正直表示の方針と矛盾）
- 言い直しの厳格判定化（詰まらせない現設計が正）
