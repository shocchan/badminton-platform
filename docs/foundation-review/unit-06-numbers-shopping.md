## 規則（5件）

### fr-numbers-basic: 数字1〜10（数字1〜10） — numberTime / draft
- ja: いち・に・さん・し／よん・ご・ろく・しち／なな・はち・きゅう／く・じゅう。4・7・9は読み方が2つあります。値段や時刻で使い分けを覚えていきます。
- zh: 数字读法：いち・に・さん・し/よん・ご・ろく・しち/なな・はち・きゅう/く・じゅう。4・7・9有两种读法，在价格・时刻中逐步掌握。

### fr-time-reading: 時刻の言い方（〜時）（时刻的说法（〜時）） — numberTime / draft
- ja: 数字＋時（じ）。特殊な読み：4時＝よじ（×よんじ）、7時＝しちじ、9時＝くじ（×きゅうじ）。「何時ですか」で時刻を聞けます。※「分」の特殊読みは次の段階で学びます。
- zh: 数字＋時（じ）。特殊读法：4時＝よじ（不是よんじ）、7時＝しちじ、9時＝くじ（不是きゅうじ）。用「何時ですか」询问时间。※「分」的特殊读法在下一阶段学习。

### fr-counters: 「〜つ」と「〜人」（量词「〜つ」和「〜人」） — numberTime / draft
- ja: 物を数える「つ」：一つ（ひとつ）・二つ（ふたつ）・三つ（みっつ）…。人は「人」：一人＝ひとり、二人＝ふたり（特殊読み）、三人からは「さんにん」のように数字＋にん。
- zh: 数东西用「つ」：一つ（ひとつ）・二つ（ふたつ）・三つ（みっつ）…。数人用「人」：一人＝ひとり、二人＝ふたり（特殊读法），三人起是数字＋にん（さんにん）。

### fr-price-yen: 値段と「いくら」（价格与「いくら」） — numberTime / draft
- ja: 値段は数字＋円（えん）：500円＝ごひゃくえん。値段を聞くときは「これはいくらですか」。
- zh: 价格是数字＋円（えん）：500円＝ごひゃくえん。问价格用「これはいくらですか」。

### fr-shopping: 買い物の基本表現（购物基本表达） — expression / draft
- ja: ほしい物を伝える：「これをください」「りんごを三つください」。ある?を聞く：「水はありますか」。
- zh: 表达想要的东西：「これをください」「りんごを三つください」。询问有没有：「水はありますか」。
