## 規則（4件）

### fr-verb-groups: 動詞の3グループ（动词的3个类别） — verbGroup / draft
- ja: まず3つに分けます。三類は「する」「来る」の2つだけ。二類は「食べる」「見る」のように「る」で終わり、その前が「え・い」の音の動詞が多いです。残りが一類です。注意：「帰る」は「る」で終わりますが一類です。
- zh: 先分成3类：三类只有「する」和「来る」两个；二类多是「食べる」「見る」这样以「る」结尾、且「る」前是e/i音的动词；其余是一类。注意：「帰る」虽以「る」结尾，却是一类动词。

### fr-masu-form: ます形の作り方（「ます形」的变法） — conjugation / draft
- ja: 一類：うの音→いの音＋ます（行く→行きます、買う→買います）。二類：る→ます（食べる→食べます）。三類：する→します、来る→来ます（きます）。
- zh: 一类：u音变i音＋ます（行く→行きます、買う→買います）。二类：去る＋ます（食べる→食べます）。三类：する→します、来る→来ます（读きます）。

### fr-nai-form: ない形の作り方（「ない形」的变法） — conjugation / draft
- ja: 一類：うの音→あの音＋ない（行く→行かない）。「買う」は「買わない」（×買あない）。二類：る→ない（食べない）。三類：する→しない、来る→来ない（こない）。例外：「ある」のない形は「ない」です。
- zh: 一类：u音变a音＋ない（行く→行かない）。「買う」变「買わない」（不是「買あない」）。二类：去る＋ない（食べない）。三类：する→しない、来る→来ない（读こない）。例外：「ある」的否定不是「あらない」，直接是「ない」。

### fr-masu-nai-choice: 文の中で肯定・否定を選ぶ（在句子中选择肯定・否定） — conjugation / draft
- ja: ていねいな肯定は「〜ます」、否定は「〜ません」（食べます／食べません）。「ない形」はふつう体の否定（食べない）で、あとの文法（〜ないでください等）でも使います。
- zh: 礼貌体肯定用「〜ます」，否定用「〜ません」（食べます／食べません）。「ない形」是普通体否定（食べない），之后的语法（〜ないでください等）也会用到。
