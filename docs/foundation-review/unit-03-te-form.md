## Can-do
- よく使う動詞のて形を読める・作れる ／ 能读・能变常用动词的て形
- 「〜てください」でお願いできる ／ 会用「〜てください」提出请求
- て形で動作をつなげられる ／ 能用て形连接动作
- 「〜ています」との接続が分かる ／ 理解与「〜ています」的联系

## 規則（6件）

### fr-te-overview: て形は何に使う？（「て形」用来做什么？） — conjugation / draft
- ja: て形はお願い（書いてください）、動作をつなぐ（買って、帰ります）、そして既に学んだ「〜ています」（住んでいます）で使います。まず形を作れるようになりましょう。
- zh: 「て形」用于请求（書いてください）、连接动作（買って、帰ります），以及已学过的「〜ています」（住んでいます）。先学会怎么变形吧。

### fr-te-g1a: 一類①：って・んで（一类①：って・んで） — conjugation / draft
- ja: 「う・つ・る」で終わる→「って」（買う→買って、帰る→帰って）。「む・ぶ・ぬ」で終わる→「んで」（読む→読んで、住む→住んで）。
- zh: 以「う・つ・る」结尾→「って」（買う→買って、帰る→帰って）。以「む・ぶ・ぬ」结尾→「んで」（読む→読んで、住む→住んで）。

### fr-te-g1b: 一類②：いて・いで・して（一类②：いて・いで・して） — conjugation / draft
- ja: 「く」で終わる→「いて」（書く→書いて、聞く→聞いて）。「ぐ」で終わる→「いで」（泳ぐ→泳いで）。「す」で終わる→「して」（話す→話して）。
- zh: 以「く」结尾→「いて」（書く→書いて、聞く→聞いて）。以「ぐ」结尾→「いで」（泳ぐ→泳いで）。以「す」结尾→「して」（話す→話して）。

### fr-te-g2g3: 二類・三類のて形（二类・三类的て形） — conjugation / draft
- ja: 二類：る→て（食べる→食べて、見る→見て）。三類：する→して、来る→来て（きて）。
- zh: 二类：去る＋て（食べる→食べて、見る→見て）。三类：する→して、来る→来て（读きて）。

### fr-te-iku-exception: 例外：行く→行って（例外：行く→行って） — conjugation / draft
- ja: 「行く」は「く」で終わりますが「行いて」ではなく「行って」。よく使う例外なのでそのまま覚えましょう。
- zh: 「行く」虽以く结尾，但不是「行いて」而是「行って」。这是高频例外，直接记住即可。

### fr-te-kudasai: 〜てください（お願い）（「〜てください」（请求）） — expression / draft
- ja: て形＋ください＝ていねいなお願い。「ここに名前を書いてください」「もう一度話してください」。
- zh: 「て形＋ください」＝礼貌的请求：「ここに名前を書いてください」「もう一度話してください」。
