## 🚧 やる前に決めること（ここがCEO判断）

### 住所をどう扱うか

GBPは原則として**住所の公開**を求めます。一方 kawabado の特商法ページは
「住所は請求により遅滞なく開示」にしています（`src/lib/legal/kawabadoLegalFacts.ts`）。
このまま住所を公開すると、**サイトの表記と矛盾します。**

抜け道ではなく正規の選択肢として、**サービス提供地域型（住所非公開）**があります。

- 実店舗を持たず、出向いてサービスを提供する事業者向けの正式なカテゴリ
- 登録時に住所は入力するが、**公開はされず**、代わりに「対応エリア」が表示される
- kawabado は公共施設を借りて開催しているので、実態にも合う

**この形なら特商法の表記と矛盾しません。** 逆に、住所公開型でどこかの会場の住所を出すと、
「その施設の代表」と誤認される恐れがあるので**やってはいけません**。

### 会場を自分の拠点として登録しない

芝園公民館も蕨市民体育館も**川口市・蕨市の施設**で、kawabado のものではありません。
これらの住所でGBPを作ると、施設側の既存リスティングと競合します。
借りている側が施設名で登録するのは筋が悪いので、しないでください。

## 貼り付ける内容

### ビジネス名
```
カワバド（川口・蕨バドミントン交流会）
```
⚠️ ここに検索語を詰め込まない（「川口 バドミントン サークル 初心者歓迎」のような名前）。
Googleのガイドライン違反で、掲載停止の対象です。実際に名乗っている名前だけにします。

### カテゴリ
- **メイン**：スポーツクラブ / スポーツ団体（`Sports club`）
- 追加候補：バドミントン教室・バドミントン用品店などは**選ばない**（教室運営でも小売でもないため）

### サービス提供地域
```
埼玉県川口市
埼玉県蕨市
埼玉県戸田市
```
戸田市は会場ではありませんが、`/ja/toda` を作って受け口にしている範囲なので入れます。
これ以上広げない（「さいたま市」「東京都」まで足すと実態と合わなくなります）。

### ウェブサイト
```
https://kawabado.com/ja/
```

### 説明文（750字以内）
```
カワバド（川口・蕨バドミントン交流会）は、埼玉県川口市・蕨市で平日の夜に活動しているバドミントンの交流会です。

いわゆる入会制のサークルではありません。入会金も月会費も会員登録もなく、参加したい回だけ申し込む形です。合わなければ次に申し込まなければいいので、「まず1回試したい」段階の方でも来ていただけます。

平日夜19:00〜21:00の通常活動は1回600円（シャトル代込み）。持ち物はラケットと室内シューズだけです。参加者の多くがお一人での参加で、交流会形式なので来た人同士でペアを組んで打ちます。

定期的に「川口・蕨バド交流杯」という大会も開催しています。超初級・初級・中級・オープンの4クラスに分かれていて、超初級・初級は初心者の方が対象です。大会は小規模の総当たり戦にしていて、1回の参加で最低4試合以上を保証しています。

運営が中国語に対応できる中日バイリンガルのコミュニティで、日本人と中国人が混ざって打っています。

会場は芝園公民館（川口市）と蕨市民体育館（蕨市）で、どちらもJR蕨駅から徒歩圏内です。開催日は毎週固定ではないので、日程はウェブサイトでご確認ください。
```

### 営業時間

**⚠️ ここは埋めないか、慎重に。** 毎週固定の開催ではないので、
「毎週水曜19:00〜21:00」のように書くと、やっていない日に人が来ます。

選択肢は2つ。CEOが決めてください。

1. **営業時間を設定しない**（「営業時間の指定なし」）。説明文とサイトに日程を誘導する
2. 実際に開催している曜日だけを入れ、**特別営業時間**で休みの日を都度つぶす

運用の手間を考えると1が無難です。**推測で埋めるのが一番まずい**（承認済みの
「自動実行しないもの」リストにも「営業時間など確証のない情報変更」が入っています）。

### 電話番号
**空欄。** 特商法ページで「請求により開示」にしているので、ここで公開すると矛盾します。
GBPは電話が無くてもウェブサイトがあれば運用できます。

### 属性・ソーシャルプロフィール
- X（旧Twitter）：`https://x.com/kawabado`
- ⚠️ 旧ハンドル `@show_eigyouhack` は**書かない**（Xは旧ハンドルをリダイレクトせず、第三者が取得できる）

### 写真
昨日 ChatGPT で作った投稿用画像（`scratchpad/posts/`）が使えます。
ただし**GBPは実際の様子の写真のほうが強い**ので、次回の活動でコートの写真を撮って
差し替えるのがおすすめです。イラストだけだと「実在するのか」が伝わりにくい。
