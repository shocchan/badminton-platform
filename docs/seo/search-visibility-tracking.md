## 誰が

- **数字を取るのはCEO。** Search Console はAIから読めない（外部サービス・認証が要る）。
- **表を埋めるのはAI。** CEOが画面の数字を伝えたら、AIがこのファイルに追記する。
  「SEOの数字を記録して」と言えば、この様式で追記される。
- 判断（続ける／戻す／次を打つ）はCEO。AIは材料と推奨を出す。

## いつ・どこを見るか

Search Console → 検索パフォーマンス → 期間を **「過去28日」** に固定して比較する。
（期間を変えると比較にならない。毎回28日で揃える）

1. **2週間後（2026-09-12）** — 表示が付き始めたか。順位はまだ動かない。
2. **1か月後（2026-09-29）** — 順位が動いたか。**トップ title 変更の影響**が見えるのもここ。
3. 以降は月1回。

## 判断の目安

| 見えたこと | 意味 | 次の一手 |
|---|---|---|
| 検索語の数が11→15以上 | 受け皿が効いている | 同じやり方で `/warabi` へ広げる |
| `戸田 バドミントン` に表示が付いた | ゼロから土俵に乗った | 戸田の内部リンクを増やす |
| `川口 バドミントン` の順位が悪化 | **トップ title 変更が裏目** | title を元に戻す（下の手順） |
| `蕨 バドミントン` の順位が悪化 | 内部リンクが蕨から逸れた可能性 | トップの地域導線を見直す |
| 1か月経っても全部横ばい | 内部リンクとsitemapだけでは足りない | Google ビジネスプロフィール・`sameAs` へ |

### トップ title を戻す手順

変更前の値はここに残してある。戻すときは2か所を同時に直す
（`src/pages/HomePage.tsx` と `src/lib/seo/staticSeo.json`。片方だけだとテストが落ちる）。

```
旧 ja: 川口・蕨バドミントン交流会 | 平日夜バドミントン大会 川口・蕨
旧 zh: 川口・蕨羽毛球交流会 | 平日夜间羽毛球活动 川口・蕨
```

## 注意

- **数字を「良くなった」と言う前に、期間が揃っているか確認する。** 3か月と28日は比べられない。
- 季節変動がある（大会の開催有無で「川口市バドミントン大会」は動く）。
  1か月の変化を施策の効果と断定しない。
- **推測で表を埋めない。** 取れなかった数字は空欄のままにする。
