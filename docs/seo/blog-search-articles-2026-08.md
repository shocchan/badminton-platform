## 公開の手順

1. 管理画面のブログ下書き一覧から開く（プレビューは `https://kawabado.com/ja/blog/{id}`、管理者ログイン時のみ）
2. `【要確認：…】` を埋めるか段落ごと消す
3. 文体・事実をCEOが確認
4. 公開する（`status='published'` と `published_at` がセットされる。既存19本は全件セットされているので、
   管理画面の公開操作で問題ない＝**sitemapに載る**）
5. **一度に全部公開しない。** 同日に8本出すと不自然なので、週2本くらいに分ける

## 取り消したいとき

```sql
DELETE FROM blog_posts WHERE id BETWEEN 37 AND 44 AND auto_generated = true;
```

`auto_generated = true` の条件を必ず付けること（人が書いた記事を巻き込まないため）。
