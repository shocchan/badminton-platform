# Search Console 手動作業リスト（CEO用）

**Google 側の操作はAIが行いません。** 認証が要る外部サービスで、誤操作が検索露出に直接効くため。
ここに書いてあることをCEOが自分で実行してください。所要は初回15分ほど。

対象プロパティ: `https://kawabado.com/`

---

## 本番反映の直後にやる（1回だけ）

### 1. sitemap を再送信する

サイトマップは自動生成なので中身は最新ですが、**Googleに「更新した」と伝える**ために送り直します。

1. Search Console → 左メニュー **「サイトマップ」**
2. すでに `sitemap.xml` が登録されているはず。**削除はしない**
3. 「新しいサイトマップの追加」に `sitemap.xml` と入力 → 送信
4. ステータスが「成功しました」になり、検出URL数が増えていることを確認

> 数え方の目安：2026-08-29 時点で 113 URL。地域ページ2枚 × 日中2言語 = 4本ぶん増えています。

### 2. `/ja/kawaguchi` をURL検査する

1. Search Console 上部の検索窓に `https://kawabado.com/ja/kawaguchi` を貼って Enter
2. 「URLがGoogleに登録されていません」と出る（新設ページなので正常）
3. **「公開URLをテスト」** を押す
4. 「URLはGoogleに登録できます」と出ることを確認
   - ここで「ページの取得に失敗」等が出たら、**AIに画面のスクリーンショットを見せてください**
5. **「インデックス登録をリクエスト」** を押す

### 3. `/ja/toda` をURL検査する

`https://kawabado.com/ja/toda` で 2 と同じ手順。

### 4. インデックス登録リクエスト（上の2・3に含まれます）

- 1日にリクエストできる回数には上限があります。**2本だけ**にしてください。
- 中国語版（`/zh/kawaguchi`・`/zh/toda`）は**リクエスト不要**です。
  sitemap から辿られます。日本語検索には出さない前提のページなので急ぎません。
- リクエストしても**すぐには登録されません**（数日〜2週間）。何度も押さないでください。

---

## 2週間後（2026-09-12 ごろ）

### 5. Search Console を比較する

`docs/seo/search-visibility-tracking.md` の表を埋めます。

1. 検索パフォーマンス → 期間を **「過去28日間」** に設定
2. 「合計表示回数」「合計クリック数」「平均CTR」「平均掲載順位」の4つを全部オンにする
3. **クエリ タブ**：`カワバド` `川口市 バドミントン` `蕨 バドミントン` `戸田 バドミントン`
   `芝園公民館` を確認。表示された検索語の**総数**もメモ（表の下に件数が出ます）
4. **ページ タブ**：`/ja/kawaguchi` `/ja/toda` の表示・クリックを確認
5. 数字をAIに伝えれば、追跡ファイルに記録されます

この時点では**順位はまだ動きません**。見るのは「表示された検索語が増えたか」だけです。

### 6. インデックスされたか確認

ページ → 「登録済み」の件数が増えているか。
`/ja/kawaguchi` をURL検査して「URLはGoogleに登録されています」になっていれば成功です。

## 1か月後（2026-09-29 ごろ）

### 7. トップページ title 変更の影響を確認する ← **ここが一番大事**

トップの title を変えたので、**すでに順位のあった語が下がっていないか**を見ます。

1. クエリ タブで `川口 バドミントン` `川口市バドミントン大会` `蕨 バドミントン` の
   **平均掲載順位**を、基準値（9.1 / 7.7 / 6.9）と比べる
2. 明らかに悪化していたら、AIに「トップのtitleを戻して」と伝えてください
   （戻す手順とtitleの旧値は `search-visibility-tracking.md` に残してあります）
3. 悪化していなければそのまま。改善していれば `/warabi` へ進む判断材料になります

### 8. 「蕨 バドミントン」がどのURLで出ているか確認する

`/warabi` ページを作るかどうかの判断材料です（`docs/seo/warabi-page-decision.md`）。

1. 検索パフォーマンス → **クエリ** タブ → `蕨 バドミントン` をクリックして絞り込む
2. そのまま **「ページ」** タブに切り替える
3. 出てきたURLの数をメモしてAIに伝えてください

| 見えたもの | 判断 |
|---|---|
| 1本だけ（トップか `/ja/venues`） | 健全。`/warabi` は作らない |
| 3本以上に分散 | 既に共食いしている。`/warabi` で集約する価値あり |

## やらないこと

- **URL削除ツールは使わない。** 消したいページがあってもここでは消さない
- **同じURLへ何度もインデックス登録リクエストを送らない。** 早くはならない
- **sitemap を削除しない。** 再送信は「追加」で行う
- 数字が思ったように動かなくても、**1か月未満で施策を取り消さない**
