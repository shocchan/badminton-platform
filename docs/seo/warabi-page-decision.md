# `/warabi` ページを作るか — 判断: **HOLD**（2026-08-29）

川口・戸田の地域ページを作った流れで「蕨も作るべきでは」という話になったが、**作らない。**
理由と、作る条件を残す。

## 結論

| | |
|---|---|
| 判断 | **HOLD（今は作らない）** |
| 主な理由 | 蕨は既に勝っている（6.9位）。競合ページを足すと、動いている信号を割る |
| 再検討する条件 | 下の「CREATEに切り替える条件」を1つでも満たしたとき |
| 代わりに今やったこと | トップ本文から `/ja/venues`（蕨市民体育館を title に持つページ）へ導線を通した |

## 根拠1: 蕨はすでに最良のクエリ

Search Console 実測（〜2026-08-21・3か月）:

| クエリ | クリック | 表示 | 順位 |
|---|---|---|---|
| **蕨 バドミントン** | **5** | **25** | **6.9** ← サイト内で最もクリックが多い |
| 川口市 バドミントン | 0 | 2 | 18.0 |
| バドミントン 川口 | 0 | 1 | 17.0 |

**川口と蕨は状況が違う。**
川口は「どのページも受け皿になれていない（18位）」＝新規ページは純増だった。
蕨は「Googleが既に受け皿を決めていて、それが機能している（6.9位・クリック5）」。
ここに同じ語を狙うページを足すのは、**動いているものを割りに行く**行為になる。

## 根拠2: サイト全体が既に「蕨のバドミントンのサイト」になっている

団体名そのものが「川口・蕨バドミントン交流会」なので、蕨は全ページに入っている。

| 指標 | 値 |
|---|---|
| title に「蕨」を含むページ | **21 / 22** |
| description に「蕨」を含むページ | **20 / 22** |
| プリレンダ本文で蕨に言及するページ | 17 |

`/warabi` を足すと、**21ページと競合する**ことになる。
とくに `/ja/venues`（title: 芝園公民館・蕨市民体育館 会場ガイド）とは狙いがほぼ重なる。

## 根拠3: 蕨で語れる実体が薄い（本番DB実測 2026-08-29）

| 種別 | 芝園公民館（川口市） | 蕨市民体育館（蕨市） | その他 |
|---|---|---|---|
| **大会**（公開済み8件） | **8件** | **0件** | 0 |
| **通常活動**（35件） | 23件 | **10件** | 幸栄公民館1・テスト1 |

- **蕨市での大会は1件も無い。** 大会は全部が川口市の芝園公民館。
- 蕨市民体育館は通常活動のみ（全体の約3割）。

`/kawaguchi` は「大会も通常活動もここ」と書けたが、`/warabi` は
「通常活動を月に数回やっています」しか書けない。
**中身の薄いページを地域名で足すのは、いちばんやってはいけない形。**

## 根拠4: cannibalization（共食い）の具体的な形

`/warabi` を作った場合に起きうること:

1. Google が「蕨 バドミントン」に対して トップ / `/venues` / `/warabi` のどれを出すか迷う
2. 迷っているあいだ、6.9位が一時的に下がる（**クリック5がゼロになりうる**）
3. 落ち着いた先が `/warabi` でも、中身が薄いのでCTRは上がらない
4. 元に戻すには `/warabi` を消す必要があり、消したURLは404/リダイレクトの後始末が残る

得られるものが「今より少し良い順位」でしかないのに、失うものが
**サイト内で唯一クリックが取れているクエリ**なので、割に合わない。

## 未確認（CEOにしか取れない情報）

**「蕨 バドミントン」で実際にどのURLが表示されているかは、まだ分かっていない。**
AIからは Search Console を読めないため。次の確認をお願いしたい:

> Search Console → 検索パフォーマンス → クエリ タブで `蕨 バドミントン` を選択 →
> **「ページ」タブに切り替える** → 表示されているURLを確認

結果によって判断が変わる:

| 見えたもの | 意味 | 次 |
|---|---|---|
| トップ（`/ja/`）1本 | 健全。団体名で受けている | **HOLD 継続** |
| `/ja/venues` 1本 | 会場ページが受けている | **HOLD 継続**。venues を厚くする |
| 3本以上に分散 | 既に共食いしている | `/warabi` で1本に集約する価値あり → **CREATE 再検討** |

## CREATEに切り替える条件

1つでも満たしたら作り直しを検討する。

1. **蕨市民体育館で大会を開催し始めたとき**（実体が増える＝書ける中身ができる）
2. 上の確認で「蕨 バドミントン」の着地ページが**3本以上に分散**していると判明したとき
3. `蕨 バドミントン` が5位以内に定着したのに**クリックが伸びない**とき
   （＝表示はされているがスニペットが刺さっていない。専用ページで改善の余地がある）
4. `蕨市 バドミントンサークル` のような**より具体的な語**で表示0が続くとき
   （川口で起きていたのと同じ「受け皿が無い」状態）

## 代わりに今回やったこと

- トップページ本文に地域導線を追加し、**蕨は `/ja/venues` へ送る**
  （新しいURLを作らずに、既に蕨で評価されている可能性が高いページへ内部リンクを集める）
- `/ja/toda` から `/ja/venues` へのリンク（蕨駅からの徒歩分数を持つページ）
