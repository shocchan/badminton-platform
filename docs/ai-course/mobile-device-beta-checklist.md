## 代表Journey（各端末で1周）

順路: ログイン → ホーム → ことば図鑑 → 最下部「初回学習を安全に試す」→
目標選択 → 短い確認（診断）→ 3語学習 → 自己評価 → 問題 → 完了（まとめ）→
復習予定を見る → 再読込 → 中文へ切り替え

## 端末固有の確認（両端末）

- [ ] 下部ナビ（ホーム/AI会話/ことば/しくみ/その他）が親指で届く・誤タップしない
- [ ] 画面下部のCTA（sticky想定位置）がホームバー／ジェスチャー領域と重ならない（safe area）
- [ ] ソフトキーボードが出たとき入力欄が隠れない・閉じたあとレイアウトが戻る
- [ ] 画面回転（縦→横→縦）でレイアウトが壊れない・学習位置が失われない
- [ ] 中国語の長文（usageNote・例文訳）が切れずに折り返す
- [ ] ふりがな（ruby）が小さすぎず・行間を壊さない
- [ ] スクロールが引っかからない（慣性・バウンス）
- [ ] ブラウザの「戻る」で学習が二重記録されない・変な画面にならない
- [ ] 再読込（プルリフレッシュ含む）で壊れない
- [ ] VoiceOver（iPhone）: 主要ボタンが読み上げられ、フォーカス順が自然
- [ ] TalkBack（Android）: 同上
