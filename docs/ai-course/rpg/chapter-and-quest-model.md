# 章・エリア・クエストのモデル

作成: 2026-07-28 ／ 既存の攻略ルート・Unitを**捨てずに対応づける**。

## 対応関係

| RPG概念 | 既存概念 | 説明 |
|---|---|---|
| **Chapter（章）** | 攻略ルートの一区切り | 物語の一区切り。1エリアが基本 |
| **Area（エリア）** | — | 地図上の場所。霧の濃度を持つ |
| **Quest（クエスト）** | Unit | 学習の一まとまり。3〜5個で章を構成 |
| **Encounter（遭遇）** | 会話練習／AI会話 | 人物との対話 |
| **Checkpoint（関門）** | 診断・問題 | 選択式の突破判定 |
| **Chapter最終クエスト** | Unit完了条件の集大成 | 複数の語彙・文法・会話を組み合わせた場面攻略 |

## Chapterが必ず持つもの

```
Chapter {
  物語上の目的      // 例: 宿に泊まれるようになる
  日本語上の目標    // 例: 自己紹介ができ、名前と出身を伝えられる
  語彙              // vocabularyItemIds[]
  文法              // grammarItemIds[]
  会話              // conversationPracticeIds[]
  診断              // diagnosticSetId
  復習              // reviewKeys[]（間隔反復へ接続）
  最終クエスト      // finalQuest
  解放されるもの    // unlocks: 場所・人物・物語・拠点の装飾
}
```

**どれか一つでも欠けている章は「作成中」であり、公開しない。**

## 章末クエストの作り方（10問テストをBoss戦と呼ばない）

章末は、**複数の語彙・文法・会話を同時に使う現実的な場面攻略**にする。

### 合格の形

1. 場面が提示される（相手・状況・目的）
2. 主人公が何を言うか選ぶ／入力する（複数ターン）
3. 相手の反応が変わる（言い方が不適切なら相手が困る）
4. 目的を達成できたかで判定する

### 章末クエストの例（既存教材と対応）

| 章 | 場面 | 使う語彙・文法 |
|---|---|---|
| 1 ミナト | 宿で名前と出身を伝えて泊まる | 名前・出身・です／ます |
| 3 トオリミチ | 駅員に事情を聞いて乗り換える | 交通語彙・〜たいです・すみません |
| 5 ユカリの森 | 友達へ遅れることを伝え、新しい予定を決める | 連絡・約束・〜ので・〜てもいいですか |
| 6 ハタラキ区 | 上司に問題を説明し、相談する | 報告・相談・〜のですが・敬語・N3文法 |
| 4 イチバ通り | 店員へ希望を伝えて買う | 数量・値段・〜をください・〜はありますか |

**禁止**: 単に問題を10問並べて「ボス」と呼ぶこと。

## クエストの粒度

- 1クエスト = 10〜15分で完了できる
- 1クエスト = 新しい語彙3〜5語 or 文法1〜2項目 が上限
- 1章 = クエスト3〜5個

## 解放（unlocks）の種類

| 種類 | 例 |
|---|---|
| 場所 | 次のエリアへの道が開く |
| 人物 | 新しい人と話せるようになる |
| 物語 | 章の背景が分かる／前章の台詞に意味がつく |
| 読めるもの | 看板・手紙・掲示が読めるようになる |
| 拠点 | 部屋に置けるものが増える |
| 称号 | 主人公の呼ばれ方が変わる |
| 記憶のかけら | 復習達成のコレクション |

## 復習の物語化（既存の間隔反復を維持したまま）

| 演出 | 実装 |
|---|---|
| 以前会った人物から依頼が来る | 復習予定の語彙を、その語彙を教えてくれた人物から再提示 |
| 昔通った場所に変化が起きる | 再訪時にAreaの見た目・台詞を差し替え |
| 忘れかけた言葉が必要になる | 期限が来た語彙を新しい場面の必須表現にする |
| 同じ表現を別の人物に使う | 同一 `reviewKey` を別 `encounterId` で出題 |
| 手紙や記録を読み直す | 過去の会話ログを読み物として再提示 |

**同じ問題をそのまま再表示するだけにしない。** 別場面・別人物・別文脈で確認する。
ただし**間隔（翌日/3日後/7日後）は変更しない**。

## 進行の解放条件

```
次エリア解放 = 章の全Quest完了 AND 章の必修語彙のMastery条件を満たす
```

満たさない場合も行き止まりにせず、「この町でもう少し話してみましょう」という
復習クエストを提示する（[adventure-learning-loop.md](adventure-learning-loop.md) 参照）。
