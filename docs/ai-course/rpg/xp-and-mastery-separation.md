# 冒険値と日本語力の分離

作成: 2026-07-28 ／ **この分離を崩す実装は、どんな理由があっても入れない。**

## なぜ分けるのか

ゲームの気持ちよさは「続ければ必ず上がる」ことから生まれる。
日本語力は「続けただけ」では上がらない。
この二つを同じ数字にすると、**簡単な問題を繰り返すだけでレベルが上がり、
実力が上がったと誤解する**設計になる。それは学習者を裏切る。

## 二つの軸

### 冒険値（Adventure XP）— 行動の量

| 加算対象 | 例 |
|---|---|
| 学習した | 今日の3語を終えた |
| 継続した | 連続日数・久しぶりの再開 |
| クエストを完了した | 章の目的を達成した |
| 新しい場面に挑戦した | 初めてのAI会話・初めての敬語場面 |
| 復習した | 予定された復習を実施した |

- **正解・不正解に関わらず加算しうる**（挑戦そのものを称える）
- 減らない。過去の努力は消えない
- 冒険者ランクの根拠になる

### ことばの力（Mastery）— 実際に使える度合い

| 判定対象 | 意味 |
|---|---|
| 自力で正解 | ヒントなしで正解した |
| 別日に再現 | 翌日／3日後／7日後に再度できた |
| 別文脈で使用 | 違う場面・違う問題形式でできた |
| 会話で使用 | 練習ではなく会話の中で使えた |
| 聞き取り | 音として理解できた |
| 言い直し | 指摘を受けて自分で直せた |
| 定着確認 | 間隔をあけて安定している |

- **既存の `masteryState`・間隔反復ロジックがそのまま担当する**
- RPG層はこれを読むだけ。**書き込んではならない**
- 冒険値では絶対に上がらない

## 実装上の不変条件（テストで固定する）

1. 冒険値の加算処理が `masteryState` を書き換えない
2. 冒険値・冒険者ランクが復習間隔の計算に入力されない
3. 章の進行条件に「冒険値がN以上」だけを使わない（必ずMastery条件を併用）
4. 冒険者ランクをJLPTレベルとして表示しない
5. 学習者向け画面で、冒険値の増加を「日本語力が上がった」と表現しない

## 表示の言い分け

| ✅ 使ってよい | ❌ 使ってはいけない |
|---|---|
| 冒険者ランクが上がりました | レベルアップ！日本語力が上がりました |
| 今日も冒険を進めました | N3に近づきました（冒険値を根拠に） |
| この言葉は、まだ霧の中です | あなたはN3レベルです |
| 3日後にもう一度会いましょう | もう完璧です |

## 進行条件の作り方（章クリア判定）

```
章クリア = 冒険条件 AND 学習条件

冒険条件（例）: 章内のQuestをすべて完了した
学習条件（例）: 章の必修語彙のうち80%が「自力正解＋別日再現」に到達している
```

**学習条件を外して章を進められる設計にしない。**
ただし、学習条件に届かない場合も「行き止まり」にはせず、
「もう一度この町の人と話してみましょう」という復習導線を必ず出す。

## 既存XPとの関係

既存実装の `XP` は学習行動の記録として残っているが、
RPG層の冒険値とは**別勘定**として扱う。統合する場合は、
上記の不変条件を満たすことを確認したうえで、人間の承認を得てから行う。
現時点では既存XPに触れない。
