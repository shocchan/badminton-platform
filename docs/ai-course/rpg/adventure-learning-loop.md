# 冒険と学習のコアループ

作成: 2026-07-28 ／ 既存の学習フローを**演出で置き換えず、包む**。

## 基本ループ

```
① 世界地図（霧の濃さで進める場所が見える）
        ↓
② 今日の冒険（既存「今日の3語」「3分復習」を章の文脈で提示）
        ↓
③ 今回の目的（何が言えるようになると先へ進めるか）
        ↓
④ 学ぶ（語彙 → 文法 → 会話練習）※既存エンジンそのまま
        ↓
⑤ 関門（選択式・既存の診断/問題ロジック）
        ↓
⑥ 人物と話す（AI会話 or スクリプト練習）
        ↓
⑦ クエスト完了
        ↓
⑧ 冒険値 → 世界が変わる（霧が晴れる・道が開く・人物が増える）
        ↓
⑨ 翌日／3日後／7日後、別の人物・別の場面で再登場（既存の間隔反復）
        ↓
⑩ 次のエリアへ
```

## 各ステップの実装対応（既存資産の再利用）

| ステップ | RPG層で足すもの | 既存で使うもの（変更しない） |
|---|---|---|
| ① 世界地図 | Area表示・霧の濃度・解放状態 | `masteryState`・復習予定から導出 |
| ② 今日の冒険 | 章の文脈・案内人の一言 | 今日の3語／3分復習／間隔反復Repository |
| ③ 今回の目的 | 物語上の目的文 | Unit完了条件・攻略ルート |
| ④ 学ぶ | 場面の絵・人物の立ち位置 | Vocabulary/Grammar Item・Sense/Usage |
| ⑤ 関門 | 「通れた／まだ霧が濃い」の言い換え | 診断・問題プール・正誤判定（**規則不変**） |
| ⑥ 人物と話す | 人物の設定・話す理由 | AI会話・スクリプト練習・言い直し |
| ⑦ 完了 | クエスト完了演出 | Journey contract・completionSnapshot |
| ⑧ 報酬 | 冒険値・解放 | XP（既存）とは**別勘定** |
| ⑨ 再登場 | 別人物・別場面での再提示 | 翌日/3日後/7日後スケジュール（**間隔不変**） |
| ⑩ 次エリア | 解放条件の表示 | Unit完了条件 |

## 「進んだ実感」の作り方（数字を増やすだけにしない）

クエスト完了時、次のうち**最低1つ**が実際に変化しなければならない。

- 新しい会話が聞ける（人物の台詞が増える／変わる）
- 新しい道・エリアが開く
- 看板・手紙・掲示が読めるようになる（それまでは霧で読めなかった）
- 過去の出来事の意味が分かる（前章の台詞に注釈がつく）
- 新しい人物に会える
- 拠点に持ち帰れるものが増える

**何も変化しないクエストは作らない。** 変化がないなら、それはクエストではなく練習である。

## 失敗時の扱い

- 「負け」「ゲームオーバー」を作らない
- 間違えた場合は「まだ霧が濃い」として、その語彙・文法を復習予定へ回す（既存ロジック）
- 人物は去らない。同じ場所へ戻れば何度でも話せる
- 既存のRecovery（中断・部分成功・schema異常）はRPG層でも壊さない

## 学習ロジックを守るための禁止事項

- 演出の都合で正解を通す・不正解を見逃す
- 冒険値のために復習間隔を短縮／延長する
- 「進みたいから」という理由で未習得の語彙を習得済みにする
- 関門の合格ラインを演出上の理由で下げる
- 章を進めるために診断をスキップさせる

## 一日の想定プレイ

10〜15分で「今日の冒険」を1つ完了できること。長時間の連続プレイを前提にしない。
社会人が通勤前・昼休み・寝る前に触れる想定。
