# PRODUCT CANON — AI日本語コース（N2／N3 Adaptive Adventure）

**このファイルはAI日本語コース開発における最上位のプロダクト判断基準である。**

実装・UI文言・データ設計・AI作業promptで判断に迷ったときは、機能仕様書ではなくここを見る。
ここと矛盾する実装は、実装のほうを直す。ここを変えるときは decision log に理由を残す。

- 整合監査: `docs/ai-course/product-alignment-audit.md`
- 運用手順: `docs/ai-course/PILOT_OPERATIONS.md`
- 判断の履歴: `docs/ai-course/adventure-v2/decision-log.md`

---

## 0. これは何か

**中国語母語話者向けの、日本語の「読めるのに話せない」を終わらせる有料伴走サービス。**

技術実験ではない。学習者が金を払い、日本語力が伸び、JLPTに近づき、続けたいと思う商品である。
売上は Claude Code・OpenAI API・Supabase・Cloudflare・教材制作・学習者サポートを
継続するための原資であり、**学習成果と信頼からしか作らない**。

やらないこと: 誇大表示・合格保証・解約妨害・未完成機能の完成表示。

## 1. 中核コンセプト

> **目的地は本人が選ぶ。**
> **現在地はAIが測る。**
> **今日の一歩はAIが決める。**

この3行が商品のすべてである。どれか1つでも崩れたら商品ではなくなる。

- 目的地を本人から奪えば、それは押しつけになる
- 現在地を測らなければ、教材は当てずっぽうになる
- 今日の一歩を本人に投げれば、それは教材の詰め合わせにすぎない

---

## 2. 学習者が選ぶもの / AIが決めるもの

| 学習者が選ぶ | AIが決める |
|---|---|
| N2合格 / N3合格 / 会話力向上 / JLPT＋会話 | 現在地（診断で測る） |
| 目標期限（試験日） | 不足している基礎 |
| 1日に使える学習時間 | 攻略ルート |
| 案内の先生（翔子先生 / 悠斗先生） | 今日学ぶ内容 |
| | 復習する内容とタイミング |
| | 問題の難易度 |
| | 次の冒険 |
| | 人間レッスンで扱う候補 |

**学習者に選ばせてよいのは「どこへ行きたいか」であって、「今日どの教材をやるか」ではない。**

---

## 3. 絶対原則（18）

1. **目的地を本人から奪わない。** N2志望者の実力がN3未満でも、目的地はN2のまま
2. **基礎不足は降格ではなく経由地。** 「N3へ下げます」ではなく「N2攻略の途中でN3を通る」
3. **Homeの主要CTAは常に一つ。** 同格のボタンを並べない
4. **毎日の教材選択を本人へ投げない。** 「今日は何をしますか？」と聞かない
5. **JLPTと会話力は別能力。** 片方の数値をもう片方へ流用しない
6. **JLPT試験対策は選択式のみ。** 自由入力を試験ルートに置かない
7. **AI会話は学んだ内容を使う定着工程。** 雑談機能ではない
8. **問題数ではなく能力変化を成果とする。** 「1万問あります」は成果ではない
9. **初見・別日・遅延定着を重視する。** 同じ問題の再演で「できた」と言わない
10. **人間レッスンはAI学習記録を使う。** しょっちゃんが一から聞き直さない
11. **RPGは学習構造を分かりやすくする手段。** 目的ではない
12. **世界観の名称だけで学習目的を隠さない。** 「ソラノ塔」だけでなく「N2文法」も併記する
13. **未判定を0％として表示しない。** 測っていないものは「未判定」と書く
14. **一技能だけで合格準備度を出さない。** 文法満点でも総合は出さない
15. **学習後は必ず次の一歩を示す。** どの画面も行き止まりにしない
16. **教材一覧・地図は第二階層。** 探さないと学習できない設計にしない
17. **有料価値は量ではなく個別伴走。** 「あなた専用の今日の一歩」が商品
18. **継続率と売上は学習成果と信頼から作る。** 煽り・機能追加では作らない

## 4. 正準学習Journey（唯一の正解）

### 初回

```
目的を選ぶ → 目標レベル・期限を決める → 先生を選ぶ
→ 現在地を診断する → AIが攻略ルートを作る → 最初の冒険を開始する
```

### 毎日

```
Homeを開く → 今日の冒険を一つ提示 → 復習
→ 必要な語彙・文法・読解・聴解 → 問題バトル
→ 必要に応じてAI会話 → レポート → 言い直し → 復習登録
→ 今日の成長表示 → 次の一歩
```

### 定期

```
技能別準備度 → 中ボス → 総合ミニ模試
→ しょっちゃんとのオンラインレッスン → 学習ルートの方向修正
```

**禁止**: 教材一覧・攻略マップ・復習一覧・模試一覧を「探さなければ学習できない」設計。
これらは第二階層（折りたたみ）に置き、Journeyの本線からは自動で必要なものが出る。

## 5. Home の第一ビュー（商品の中心）

Homeを開いた学習者が最初に見るのは、**今日の冒険だけ**である。

必須表示:

| # | 項目 | 例 |
|---|---|---|
| 1 | 最終目的地・試験までの日数 | N2合格まであと126日 |
| 2 | 現在地 | いまN3の後半（言語知識） |
| 3 | 今鍛えている能力 | 言語知識｜文法 |
| 4 | 今日のstepと所要時間 | 今日の冒険 約12分 |
| 5 | stepの一覧（連番） | 1.復習2問 2.N3文法1テーマ 3.短文読解1問 4.AI会話 |
| 6 | **Primary CTA 一つ** | ［まず復習から始める］ |
| 7 | 選んだ先生からの短い案内 | 「今日は12分。まず復習から始めましょう。」 |

完了後は同じCTAが次のstepへ変わる。全step完了で「今日の冒険を締めくくる」へ変わる。

教材一覧・地図・模試・準備度・設定は**折りたたまれた第二階層**に置く。

## 6. 成長実感（有料価値が伝わる形）

### 毎日の完了画面

- 今日できたこと
- 覚えた語彙・表現
- **直した表現**（AI会話の言い直し素材）
- **今回伸びた技能**
- 次回復習日
- **次の冒険**

### 毎週のまとめ

- 学習日数 / 学習時間 / 完了した冒険
- 定着した項目 / 技能別の変化 / 苦手項目
- 来週の重点
- 次回の先生レッスン候補

**数値を並べない。「先週より何ができるようになったか」が分かる構造にする。**
未計測の能力を成長したように表示しない（原則13）。

---

## 7. AI と しょっちゃん の役割

| AIが担当 | しょっちゃんが担当 |
|---|---|
| 毎日の学習 | 目標設定 |
| 問題演習 | 苦手の原因分析 |
| 間隔反復 | 学習方針の変更 |
| 短い会話 | 読解・聴解の考え方 |
| 言い直し | 試験戦略 |
| 学習記録 | 重要な会話練習 |
| 弱点検出 | モチベーション支援 |

**AIは量を担当し、人は難所と方向を担当する。**

先生レッスン準備では学習履歴を大量表示しない。**次回扱う候補を最大3件**に絞る。
学習者側にも「次の先生レッスンで相談すること」を**最大3件**表示する。

---

## 8. 数値の定義（混同しない）

| 用語 | 定義 |
|---|---|
| **Word Coverage** | active CORE語のうち、最低必要問題数（2問以上）がある割合 |
| **Exam-format Coverage** | JLPT出題形式別に十分な問題がある割合 |
| **Human-reviewed Coverage** | 人間が目視確認した割合 |
| **Pilot Beta Coverage** | 自動検査＋独立AIレビューを通った割合 |

**「CORE Question Coverage 100%」を「N2／N3試験を100%網羅」と表示してはならない。**
前者は自社が扱うと決めた語に問題が付いている割合であり、試験範囲の網羅率ではない。

---

## 9. この文書の使い方

新しい実装・AI作業promptを書くときは、冒頭で必ずこう指示する。

> `docs/ai-course/PRODUCT_CANON.md` を読み、絶対原則18項目と正準Journeyに従うこと。
> 矛盾する場合はPRODUCT_CANONが優先する。

判断が canon から外れる場合は、外れる理由を `decision-log.md` に残してから実装する。
