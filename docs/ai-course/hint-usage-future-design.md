# ヒント使用記録の将来設計（今回は実装しない・CEO決定 2026-07-28）

決定事項: **今回はヒント使用記録を追加しない。** 記録していない項目を0件として
表示しない現状を維持する（`answeredWithSupportCount` は null・画面非表示）。
本書は将来実装するときの設計メモのみ。Release Gateには含めない。

## 候補イベント（単なる hintUsed 1フラグにしない）

| イベント | 意味 | 習熟判定への使い方 |
|---|---|---|
| `hint_opened` | ヒントを開いた（見ただけ） | 単独では減点しない |
| `hint_applied` | ヒントを見てから回答した | supported（補助あり正解）の根拠 |
| `answer_revealed` | 答えを表示した | その回はindependent扱いにしない |
| `self_corrected_after_hint` | ヒント後に自力で言い直した | supportedとindependentの中間として扱える |

## 原則

- **単純な hintUsed だけで習熟を判定しない。** 「開いた」と「頼った」を区別する
- 記録が無い期間のデータと混ざるため、導入後も過去分は null のまま（0に埋めない）
- 保存先は正式DB保存（`dimension_states` 拡張 or attempts側のイベント列）と同時に設計する
- 表示は現行の3軸モデル（クイズ正誤／感じ方／予定）の軸Aの内訳として加える
