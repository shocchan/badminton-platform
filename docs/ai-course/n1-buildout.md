## 開始時点の実測（2026-09-05）

N1は「今後追加予定」のまま、**教材がゼロ**だった。

| 要素 | 開始時 | 根拠 |
|---|---|---|
| 目標レベルの選択 | N1は選べない | `ACTIVE_TARGET_LEVELS`＝N5〜N2 / `FUTURE_TARGET_LEVELS`＝N1 |
| 語彙 | 0語 | `VOCAB_SCOPE` が N2・N3 のみ |
| 文法 | 0項目 | drafts は basic(N5/N4) / n3 / n2 の3ルートのみ |
| 読解 | 0セット | `ReadingLevel = 'N2'｜'N3'｜'N4'｜'N5'` |
| 聴解 | 0本 | `ListeningLevel` 同上 |
| ミニ模試 | 出せない | `mockLevelOf('N1')` が null |
| 準備度 | 測れない | `advReadiness` が N1 を対象外にしている |

## 方針

1. **無いものを在るように見せない。** 級を解禁するのは、その技能の在庫が実際に載ってから。
   語彙だけ載った段階で「N1模試」を名乗らない（N5/N4解禁時と同じ原則）。
2. **下の級を含める。** N1の出題範囲はN2以下を含む。`VOCAB_SCOPE.N1` は N5〜N1 を全部見る。
   構築の途中でも、生徒には「N2＋N1の一部」という形で意味のある出題になる。
3. **既存の品質ゲートをそのまま通す。** 語彙は `validate-vocab-content.ts`、
   文法は既存のdraft構造と同じ完成条件（意味・中文・接続・用法・ニュアンス・文体・
   例文2本・ふりがな・誤用注意・類似/対比・認識問題・産出問題・会話練習）を満たしたものだけ収録する。
