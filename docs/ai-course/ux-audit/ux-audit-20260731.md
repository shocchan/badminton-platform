## 3. イラスト監査（140枚）

機械検査: asset 140/140・manifest一致・duplicate hash 0・broken 0・alt ja/zh 140・overflow 0。
contact sheet: `illustration-contact-sheet.html`（140枚・メタデータつき）。

**heuristic評価（2系統subagent・実装非関与プロンプト）— human approvalではない**:

- 評価者A（ja視点・**全140枚視認**・切れていたPNGを自力で再生成して全量確認）: PASS 73 / IMPROVE 52 / REPLACE 15
- 評価者B（zh視点・92枚視認）: PASS 51 / IMPROVE 34 / REPLACE 7

**統合分類**:
- 両者一致REPLACE（4件）: `fi-suru`（人+✓のみ＝動作性なし）・`fi-kantan`・`fi-nareru`（同一S字+✓で相互衝突）・`fi-joukyou`（情報ゼロ）
- 準一致REPLACE（片方REPLACE+片方強IMPROVE・7件）: `fi-hazukashii`・`fi-kankei`・`fi-riyou`・`fi-ikura`・`fi-takai`・`fi-kanashii`・`fi-chugoku`
- **意見不一致 → human-priority（CEO目視推奨・7件）**: `fi-nihongo`・`fi-hitsuyou`・`fi-kimochi`・`fi-kibun`・`fi-riyuu`・`fi-tsumari`・`fi-sorede`（Aのみ REPLACE）
- 記号群の相互判別不能（両者一致）: カレンダー群（決まる/決める/予約/予定/習慣/最近）・緑線群（慣れる/簡単/続く/方法）・ゴール旗3重衝突（終わる/やっと/頑張る）
- **新種の欠陥（A発見）**: alt文と実描画の不一致 — 簡単=「直線」指定がS字描画・嬉しい=「両手を上げる」指定が腕下げ・関係=「線」指定が腕状。仕様→SVGの検証工程が抜けている
- **両者一致の強み**: 方向対（行く/来る・入る/出る・乗る/降りる・帰る）は矢印が全て正しい。トーン統一・低幼さなし
- **最重要指摘（B）**: `fi-chugoku` — 不正確な中国地図の描画は中国人ユーザー向けに政治的リスク。**非地図シンボルへの差し替えをP2で推奨**
- 共通弱点: チェック/×/矢印記号への依存で抽象語（する/簡単/慣れる/上手/便利/全然/状況…）が相互識別不能
- 検査体制の欠陥（B指摘）: PNG化で下2行が切れ44枚が未視認 → **フル高で再レンダリングし残44枚の再審査が必要**（監査側のTODO）
