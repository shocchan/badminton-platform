# Learner Journey（Phase 2E-1.10 §13-§17）

学習者が毎日迷わず学べるための導線。すべて labPreview + preview Repository の範囲。

## 2回目以降のJourney（現在実装済み）

1. ホーム: 第一CTAは**一つ**。優先順位（`CourseHome` の `hero`）:
   1. **語彙の期限復習**（期限超過→今日が期限。2E-1.10で追加）
   2. しくみの復習期限
   3. 途中の単元
   4. 今日の会話ミッション
   5. 次の単元
   6. 今日の3語
2. ことば図鑑トップ: 「今日の復習」カード（件数＋所要時間＋内訳は折りたたみ）→ 今日のことば → カテゴリー
3. 復習 or 今日の3語 → 問題 → 自己評価
4. **学習完了画面**: 今日できたこと／次の復習（明日 n語・3日後 n語・7日後 n語）
5. 第一CTA「今日の学習を終える」＋補助CTA「AI会話で使ってみる」「もう一度確認する」

## CTA階層（§23）

| 種類 | 見た目 | 例 |
|---|---|---|
| 第一CTA | `ActionButton variant="primary"`（Depth 3・fullWidth） | 復習を始める／今日の学習を終える |
| 第二CTA | 枠線ボタン（Depth 2） | AI会話で使ってみる／もう一度確認する |
| 補助リンク | 下線テキスト（Depth 0-1） | ロードマップを見る／内訳を見る |
| 静的カード | hoverなし | 語彙の目標・現在のパック表示 |

同じ強さのボタンを第一CTAの下に並べない（完了画面の補助CTAは弱いスタイルで明確に区別）。

## 空状態（§25）

- 期限の復習が0件: 復習カード自体を出さない（空カードを置かない）→ 今日のことばが第一表示になる
- 復習対象0件で復習画面へ来た場合: 「今は復習することばがありません」＋トップへ戻る導線
- 復習は期限分＋従来の弱点候補で補完するため、途中で行き止まりにならない

## 図と動き（2E-1.13・CEO指示「見やすく・視線が動きやすく・イメージしやすく」）

`LearningIllustrations.tsx` にまとめる。**すべてインラインSVG**で、外部ライブラリも
画像リクエストも増やさない。

| 部品 | 役割 | 置く場所 |
|---|---|---|
| ステップイラスト4種 | 各ステップが何をする所かを絵で示す | Journeyの見出し横 |
| `JourneyStepper` | 今どこか・あといくつか（番号・✓・接続線） | Journey上部 |
| `PhaseTrail` | 語の中の3段階「見る › ためす › ふりかえる」 | 練習画面 |
| `ResultBars` | 今日の結果を見て分かる | Step4・完了画面 |
| `ReviewTimeline` | 「また戻ってくる」を時間軸で示す | Step4・完了画面 |

守ること:

1. **図は理解の補助であって唯一の情報源にしない。** 件数・ラベルは必ず文字でも読める
2. 0件の項目は棒を描かない（0を強調して落ち込ませない）。0件の予定日は薄く描くが存在は示す
3. 色だけに依存しない（済み=✓・現在=塗り＋リング・未来=薄い丸と形も変える）
4. 動きは `prefers-reduced-motion` 準拠（`motion-safe:`）で200〜500msのみ
5. SVGは `role="img"` ＋ `aria-label` を必ず持つ

`learningIllustrations.test.tsx` でこれらを担保する。

## 復習予定が生まれる経路（2E-1.13で修正）

「今日のことば」（練習）は**クイズ結果と自己評価の両方**を復習スケジュールへ書く。
これが欠けると、完了画面が「忘れかけるころにもう一度出てきます」と案内しながら
復習予定が0件になる（実機で発生していた）。

| 操作 | 復習予定への反映 |
|---|---|
| クイズ誤答 | 翌日 |
| クイズ正解 | 7日後（同日の再正解では段階を進めない） |
| 「まだ不安」 | 翌日・優先度を上げる |
| 「覚えた」 | **予定は消さない**（自己申告で定着扱いにしない） |

`learningLoop.test.tsx` の「今日のことば → 復習予定の接続」で回帰を防ぐ。
