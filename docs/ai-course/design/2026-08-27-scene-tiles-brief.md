## なぜ2枚だけか

LPの生活シーンは4つある。

| 場面 | 使える絵 | 状態 |
|---|---|---|
| コンビニ・お店 | `public/ai-course/map/tile-ichiba` | **既にある** |
| 職場 | `public/ai-course/map/tile-hataraki` | **既にある** |
| 病院 | — | **これを作る** |
| 市役所 | — | **これを作る** |

4枚中2枚だけ絵にすると、揃っていないほうが目立って逆効果になる。
2枚そろってから4つ同時に実装する。**それまでLPは現状のまま**（絵無しの文字カード）。

---

## 絵柄（ここが最重要）

**必ず参照画像を添付すること。** 文章だけで同じ絵柄は出ない。

添付するファイル（この2枚をChatGPTにアップロードする）:

```
public/ai-course/map/tile-ichiba@2x.webp      ← 商店街
public/ai-course/map/tile-hataraki@2x.webp    ← オフィス街
```

この2枚は、生徒が毎日見ている冒険マップの実物。
**LPで見た絵が、買ったあとの画面にそのまま出てくる**という一致がこの依頼の目的。
新しい絵柄を作ってはいけない。

絵柄の特徴（参照画像から読み取れること）:

- 水彩・色鉛筆のような手描きの質感。デジタル塗りのつるっとした感じにしない
- 等角投影（アイソメトリック）。真上でも真横でもない、斜め上から見た角度
- 建物は**日本の実際の街並み**。ファンタジー要素を入れない
- 色は落ち着いた中間色（セージグリーン、テラコッタ、クリーム、くすんだ青）。彩度を上げない
- 線は細く柔らかい。太い黒縁取りをしない
- **背景は透明**。地面のタイル部分だけが不定形に切り抜かれている
- 建物の周りに木・自転車・ベンチなど小さな生活の要素が少し入る

## 依頼文（ChatGPTにそのまま貼る）

```
添付した2枚は、私が運営している日本語学習アプリで使っている
「冒険マップ」のタイル画像です。同じ絵柄・同じ画角・同じ色調で、
別の場所のタイルを2枚作ってください。

【共通の条件】
- 添付画像とまったく同じ絵柄（水彩・色鉛筆風の手描き質感）
- 等角投影（アイソメトリック）。添付画像と同じ角度
- 日本の実際の街並み。ファンタジー要素は入れない
- 落ち着いた中間色。彩度を上げない
- 背景は透明（PNG）。地面のタイル部分だけを不定形に切り抜く
- 建物の周りに木・自転車・ベンチなど小さな生活の要素を少し
- 人物は入れない（顔が入ると年齢や国籍の印象が付くため）
- 文字・看板の文字は入れない（言語がひとつに固定されるため）
- 出力サイズ: 幅440px以上、正方形に近い比率

【1枚目：病院・クリニック】
日本の中規模な総合病院か、地域のクリニック。
入口に車寄せ、自動ドア、駐輪場。周りに植え込み。
救急車や派手な赤十字は入れない（緊急の場面ではなく、
「予約や受付で日本語を使う場所」として描く）。

【2枚目：市役所・区役所】
日本の市役所・区役所の庁舎。
四角い公共建築、正面に階段と広い入口、掲示板、旗のポール、
前に少し広場や植え込み。役所らしい落ち着いた外観。
特定の自治体の名前やロゴは入れない。

2枚を別々の画像として出力してください。
```

## 検品（受け取ったあとに確認すること）

1. **絵柄が既存タイルと並べて違和感がないか。** 実際に `tile-ichiba` と横に並べて見る
2. **背景が本当に透明か。** 白い背景が焼き込まれていないか
3. **人物が入っていないか。** 顔が入ると印象が固定される
4. **文字が入っていないか。** 日本語の看板が入ると中国語画面で浮く
5. **特定の実在施設に見えないか。** 実在の病院・役所に見えると許可の問題が出る

## 実装するときの手順

1. 受け取ったPNGを WebP へ変換し、@1x と @2x を作る
   ```
   public/ai-course/map/tile-byoin@1x.webp   (幅220px前後)
   public/ai-course/map/tile-byoin@2x.webp   (幅440px前後)
   public/ai-course/map/tile-yakusho@1x.webp
   public/ai-course/map/tile-yakusho@2x.webp
   ```
2. 1枚あたり **@1x は15KB以下、@2x は45KB以下** に収める
   （既存タイルの実測: `tile-ichiba@1x` 9.7KB / `@2x` 29.6KB）
3. `sectionsScenes.tsx` の4カードに画像を足す。対応は:
   - コンビニ・お店 → `tile-ichiba`
   - 職場 → `tile-hataraki`
   - 病院 → `tile-byoin`
   - 市役所 → `tile-yakusho`
4. `loading="lazy"` ・ `width`/`height` 指定 ・ `alt=""` `aria-hidden="true"`
   （場面名は文字で書いてあるので、絵は装飾）
5. `lpVisuals.test.ts` に4枚ぶんの存在チェックとサイズ上限を足す

**旧デザイン（絵無しの文字カード）は、CEOが新しい見た目を確認するまで消さない。**

## 費用対効果の見立て

- 追加される重さ: 4枚 × @1x 約12KB = **約48KB**（遅延読み込みなので初回表示には乗らない）
- 現在のLP全体: 948KB。5%増
- 効くと考える理由: `#scenes` は現在1,244px（1.5画面ぶん）の**完全な文字の壁**で、
  内容は「場所」の話。文字で場所を説明するより絵のほうが速い。
- 効かなかったと分かる測り方: `#scenes` を通過した人の割合は測っていないので、
  現状では**効果を測れない**。UTMを付けて流入が増えてから、CTAクリック率で見る。
