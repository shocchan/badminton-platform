# ChatGPTに頼む画像：PC用の横長の風景（任意）

作成日: 2026-09-01
用途: AI日本語コースの販売LP、冒険テーマのヒーロー
状態: **必須ではない。いまは既存画像で成立している**

---

## いまどうなっているか

`public/ai-course/map/world-bg`（512×768の縦長・水彩）を使い分けている。

| | 出し方 | 実測 |
|---|---|---|
| スマホ | 背景として敷く（220px） | 512×191＝上から25%が見える。上下の色差121 |
| PC | 本文と同じ幅の帯（1110×180・文字を重ねない） | 512×92＝上から12%が見える。上下の色差81 |

**どちらも地平線が見えていて、絵として成立している。**

### 一度「PCでは出せない」と誤判断した経緯

2026-08-28、CEOから「PCで見ると冒険の方イマイチ」と指摘され、PCから消した。
そのとき「縦長の原画は横帯にできない」と理由を書いたが、**これは誤りだった**。

同じ画像をロードマップで 1110×200 に切って出しており、実測すると色差80で
地平線が見える。切り取りは問題なかった。

本当の原因は2つ:
- 全幅1440まで広げていた（本文の最大幅1110を超えて間延びする）
- 白いベールを重ねたうえに文字を乗せ、風景が霞んだ

**本文と同じ幅に収め、文字を重ねない帯にしたら解決した（2026-09-01）。**

---

## それでも横長を1枚起こす価値があるとしたら

いまはPCで**上から12%**しか見えていない。空と山の頂だけで、
川・森・港といった「道のり」を感じさせる部分は入らない。

横長の原画があれば、PCでも全体の風景（手前から奥へ延びる道）を出せる。
**やらなくても成立しているので、優先度は低い。**

## 依頼文（やる場合。ChatGPTにそのまま貼る）

添付する参照画像: `public/ai-course/map/world-bg@1x.webp`

```
添付は、私が運営している日本語学習アプリの「冒険マップ」の背景です。
同じ絵柄・同じ世界のまま、横長版を1枚作ってください。

【条件】
- 添付画像とまったく同じ絵柄（水彩の手描き。デジタル塗りにしない）
- 落ち着いた中間色。彩度を上げない
- 手前から奥（地平線）へ道か川が延びている構図。
  「これから旅に出る」と感じられる引きの画。
- 空は上1/3程度。残りは大地
- 人物・建物のアップ・文字は入れない
- 出力サイズ: 横2400px以上、比率はおよそ 16:5（横長）
```

## 検品

1. 添付画像と並べて絵柄が揃っているか
2. 中央に重要な要素を置きすぎていないか（左右が切られる前提）
3. 上1/3が空で、そこに文字を重ねても読めるか
4. 文字・人物が入っていないか

## 実装するとき

```
public/ai-course/map/hero-wide@1x.webp   (幅1200px前後・60KB以下)
public/ai-course/map/hero-wide@1x.avif   (同上・50KB以下)
```

`AiCourseHero.tsx` の `.lp-adv-hero-strip` の中の `<img>` を差し替え、
`width`/`height` を実寸に合わせる。`lpVisuals.test.ts` にサイズ上限を足す。

**既存の world-bg は消さない**（スマホ側と、ロードマップの帯で使っている）。
