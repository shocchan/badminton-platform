## 0. 結論（先に要点）

| 項目 | 値 |
|---|---|
| 画像の論理座標 | `viewBox 0 0 360 600`（**縦横比 3:5**）。正規化座標 = (x/360, y/600) |
| 画面上の地図幅 | `min(ビューポート幅 − 32px, 544px)`。375→**343×570px**、768・1440→**544×905px**（`max-w-xl` ＋ `px-4`） |
| トリミング | **なし**（`h-auto w-full` で全体表示）。会話ルートだけ下半分クロップ（`viewBox 0 300 360 300`、y 0.5〜1.0） |
| UI が乗る帯（全ケース和集合） | 試験レーン: x 0.20〜0.78 の蛇行帯（後述の回廊） ／ 会話レーン: 湾の外周 x 0.04〜0.96 × y 0.76〜0.98 ／ 旗ラベル: 目標ごとに4か所 ／ 雲海吹き出し: y 0.01〜0.16 |
| 画像が絶対に守ること | ①地形バンドの境界yを現行と合わせる ②道の回廊に「障害物らしい」絵を置かない ③8つの固定ランドマークは**別レイヤー**にできるよう背景にも薄く痕跡を残す程度 ④文字・看板・数字を描かない |

## 4. 画像をレスポンシブに敷く方式（提案）

### 4-1. 方針: **既存の `viewBox 360×600` をそのまま座標系に使い、風景 SVG を `<image>` に差し替える**

現行は「論理座標 SVG ＋ % 配置の HTML ボタン」で既に正規化済み。最小差分は `WorldScenery` を `<image>` に置き換えるだけで、道・ノード・雲海・ボタンの座標は一切変えない。

```tsx
// AdvWorldMap.tsx（案）— <WorldScenery uid={uid} /> の置き換え
<image href={WORLD_BG.src} x={0} y={0} width={360} height={600}
  preserveAspectRatio="xMidYMid slice" />
```

- 画像の縦横比が 3:5 でなくても `slice` で中央トリミング（`viewBox` 基準）され、**ノード座標はズレない**
- 会話ルートの `viewBox 0 300 360 300` も自動的に下半分クロップになる（追加画像不要）
- 解像度: `<image>` は `srcset` を持てないため、**2x 基準 1 枚（WebP）** を敷く。375×2=686px / 544×2=1088px 幅があれば十分 → 幅 1440px で全 DPR をカバー
- 固定ランドマーク・雲海は別レイヤーで `<image>` を論理座標に置く（`x, y, width, height` を正規化 × 360/600 で算出）

```ts
// 例: 画像マニフェスト（正規化座標で持つ。px は持たない）
export const WORLD_ASSETS = {
  bg:       { src: '/ai-course/world/bg.webp',            box: [0, 0, 1, 1] },
  minato:   { src: '/ai-course/world/lm-minato.webp',     anchor: [0.31, 0.93], w: 0.34 },  // anchor=足元中心, w=幅(正規化)
  sorano:   { src: '/ai-course/world/lm-sorano.webp',     anchor: [0.70, 0.12], w: 0.12 },
  cloudSea: { src: '/ai-course/world/cloud-sea.webp',     tileW: 1, h: 0.2 },               // 下端スカラップ付き・横リピート
} as const;
const toVb = ([nx, ny]: readonly [number, number]) => ({ x: nx * 360, y: ny * 600 });
```

### 4-2. 代替案（背景を HTML `<img>` にする）と比較

| 方式 | 長所 | 短所 |
|---|---|---|
| A. SVG `<image>`（推奨） | 差分最小・会話クロップも自動・jsdom テスト影響なし | `srcset` 不可（2x 1枚で妥協） |
| B. `<div style="aspect-ratio:3/5"><img object-fit:cover>` ＋ SVG オーバーレイ（`absolute inset-0`） | `srcset`/`loading=lazy`/`fetchpriority` が使える | 会話クロップを `object-position: 50% 100%` ＋ `aspect-ratio: 6/5` で別途実装。`overflow-hidden rounded-2xl` は維持 |

どちらも**固定ピクセル依存なし**（地図幅に追従）。HTML ボタンの 44px だけは意図的な固定（タップ領域のため）。

### 4-3. 組み込み時の注意（画像とは別の修正候補）

1. 会話ルートの旗ラベル左端 2px 見切れ → `flagX` の下限 56 → 60
2. N2 の旗ラベルが太陽 (0.867,0.077) と重なる（ラベル右端 0.862）→ 画像では太陽を x≥0.90 か y≤0.05 に逃がす、またはラベルを左寄せ
3. 背景を画像にすると**地面ブロブ色 `groundBlobColor(y)` のバンド境界**（470/336/248/96）を画像の地形と合わせる必要がある。画像側で境界を守れば変更不要
