制作は **ChatGPT が絵・モック、Claude が調査・仕様・検品・組み込み**（CEO決定 2026-08-19）。

## 1. なぜ作り直すか（実測にもとづく問題）

改善前の記録: `docs/ai-course/design/before/home/home-{ja,zh}-{375,768,1440}.png`

| # | 問題 | 実測 |
|---|---|---|
| P1 | **世界がここに無い** | 地図には港・街・霧の世界があるのに、毎日最初に開くホームは白と灰色の文字だけ。同じ製品に見えない |
| P2 | **始めるまでが遠い** | 375px で主CTA「続ける」は y≈1330 / 全高 2294。**スクロールしないと押せない** |
| P3 | **始める前に数字が6行** | 目標・現在地・攻略率・残り地域数・残り項目数・レベル・XP。単位が4種類（%・地域・項目・XP）あり、今日の話が1つも無い |
| P4 | **同じことを3回言う** | 翔子先生「今日は17分。まず語彙バトルから」→ カード「今日はこの4つだけ・約17分」→ step一覧。相棒の1行は内容ゼロ |
| P5 | **今日の進み具合が分からない** | 細い進捗バーはあるが、「4つのうち1つ終わった」が数字で出ない |
| P6 | **広い画面が空っぽ** | 1440px では中央に細い列があるだけで、左右は灰色の余白 |
| P7 | **法務リンクが学習と同じ強さ** | フッターに6リンク。毎日見る画面で学習内容と競合している |

## 2. 目的（この画面が果たす仕事）

1. 開いた瞬間に **「自分はいまこの世界のここにいる」** と分かる
2. **1画面目で押せる**（スクロールなしで主CTAに触れる。375px 想定）
3. 今日やることが **1つの塊** に見える（数字は今日のぶんだけ）
4. 毎日ひらいて **少しずつ変わる**（今日の街・進み具合・季節/時間帯）

## 3. 画面に置くもの（絵とコードの分担）

| 要素 | 誰が持つ | 備考 |
|---|---|---|
| 今日の街のヒーロー帯（現在地の風景） | **画像** | 地図の8街と同じ画風。文字は焼き込まない |
| 現在地の名前・章・攻略率 | コード | 画像の上にHTMLで重ねる |
| step の絵記号（ことば/文法/会話/読解/聴解/漢字/かな/復習） | **画像** | 単色の丸数字をやめる。透過PNG |
| 「今日のゴール」の印 | **画像** | 押印風の小さな図。中の文字はコード |
| 進捗（n/N・残り時間） | コード | 数字・a11y・アニメはコード |
| 翔子先生・相棒の一言 | コード＋既存画像 | 文言は実データから作る（飾りの偽演出をしない） |
| 法務リンク | コード | 折りたたみ or 下部の小さな行に降ろす |

**画像に文字（日本語・中国語・偽文字）・ボタン・進捗・地名を焼き込まない。** UIはすべてコード。

## 4. 素材の仕様

| 素材 | 枚数 | 比率 | 実寸(2x) | 透過 | 置き場所 |
|---|---|---|---|---|---|
| 街のヒーロー帯 | 8（ミナト/ヒノデ台/トオリミチ/イチバ通り/ユカリの森/ハタラキ街/カタチの遺跡/ソラノ塔） | **3:1** | 1152×384 | 不要 | `public/ai-course/home/hero-<id>@{1x,2x}.webp` |
| step の絵記号 | 8 | 1:1 | 192×192 | **必要** | `public/ai-course/home/step-<kind>@{1x,2x}.webp` |
| 今日のゴールの印 | 1 | 1:1 | 256×256 | **必要** | `public/ai-course/home/goal-seal@{1x,2x}.webp` |

- 重さの上限: **2x 合計 400KB 以内**（地図と合わせて 1MB を超えない）
- ヒーロー帯のセーフエリア: **下辺 30% と 左 45% に文字を重ねる**。その範囲は空か、淡くする
- 375px では帯の高さ 125px（3:1）。**遠景の情報量を上げない**（潰れる）

## 5. 画風（地図と同じ。STYLE LOCK）

- 承認済みの背景（A-v3）と画風シート、8街のタイルと**同じ**水彩＋線画、同じ光（右上から）、同じパレット
- 現代日本の旅の景色。俯瞰ぎみの3/4視点
- **禁止**: 既存ゲームの模倣、有名キャラ、AI特有の崩れた文字・幾何、子どもっぽさ、過剰な和風アイコン、写真調

## 6. ChatGPT への依頼順

1. **モック2案**（レイアウトの方向性。スマホ375幅の1画面目だけ）
   - A案: ヒーロー帯を上に敷き、その上に現在地。カードは帯の下から重なる
   - B案: 画面全体が地図の一部で、カードが半透明で浮く
   - → 2案を比べて1案を採用（1回目を無条件採用しない）
2. 採用案にそって **街のヒーロー帯 8枚**
3. **step の絵記号 8枚**
4. **今日のゴールの印**

## 7. 検品（QA）

- [ ] 文字・偽文字・ロゴ・ボタンが焼き込まれていない
- [ ] 地図の8街と同じ場所に見える（建物・色・光が一致）
- [ ] 下辺30%・左45%に文字を置いても読める（明度差 4.5:1 以上）
- [ ] 375/768/1440 で潰れない・伸びない
- [ ] 2x 合計 400KB 以内
- [ ] 人物が写り込んでいない（キャラは別素材）

## 8. 組み込みと戻し方

- feature flag `?home=v2`（既定は現行）。地図と同じ仕組みで新旧を切り替える
- 画像が無い/404 のときは**現行のホーム**にそのまま落ちる
- staging で 375/768/1440 × ja/zh × 状態（初回・途中・全部終わった日）を比較してから本番
