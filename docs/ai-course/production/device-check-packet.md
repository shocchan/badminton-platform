# 実機チェック packet（20〜30分）

staging URL: **https://staging.badminton-platform.pages.dev/ja/ai-course?app=1**
中国語版: 上のURLの `/ja/` を `/zh/` に変えるだけ。

答えかたは「番号: PASS」または「番号: FAIL ＋ 見えたもの」だけでよい。
FAILの番号さえ分かれば、こちらで直せる。

## A. iPhone（Safari）

| # | 操作 | 期待 |
|---|---|---|
| A1 | 上のURLを開く | 数秒以内に学習ホームが出る。白い画面のままにならない |
| A2 | 画面を縦のまま下までスクロール | 横方向にはみ出さない。文字が切れない |
| A3 | 「ことば」を開く | 語のカードに**絵が出ている**（灰色の空枠ではない） |
| A4 | 語を1つ開く | 大きい絵＋意味＋例文が出る |
| A5 | その語で会話練習を始める | その語に合った質問が出る（毎回同じ質問ではない） |
| A6 | 入力欄をタップ | キーボードが出ても送信ボタンが隠れない |
| A7 | 章を1つ開いてQuestを1つ進める | 進んで、XPが増える |
| A8 | 画面を閉じてもう一度開く | 進んだところから戻る（最初に戻らない） |
| A9 | 機内モードにして操作 | 「オフラインのようです」と出る（無言で固まらない） |

## B. Android（Chrome）

A1〜A9 と同じ。違いがあった番号だけ書けばよい。

## C. VoiceOver（iPhone・最低限）

設定 → アクセシビリティ → VoiceOver をオン。

| # | 操作 | 期待 |
|---|---|---|
| C1 | ことば図鑑の絵を選ぶ | 絵の内容が読み上げられる（「イメージ」だけで終わらない） |
| C2 | 読み込み中の画面 | 「読み込み中」等が読み上げられる（無言で待たされない） |
| C3 | 会話でAIの返事を待つ | 「考えています」が読み上げられる |
| C4 | 中国語表示で C1〜C3 | 中国語で読み上げられる（日本語が混ざらない） |

## D. TalkBack（Android・最低限）

C1〜C4 と同じ。

回答例:

A1〜A8 PASS

その他 PASS
