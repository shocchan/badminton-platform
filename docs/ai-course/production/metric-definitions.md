# 指標の定義（数値の混同を防ぐ）

作成: 2026-07-28 ／ CEO指摘（191と102の矛盾）を受けて作成。**以後この定義以外で数値を使わない。**

## 191 と 102 の決着

**どちらも正しいが、測っているものが違った。** 報告時に区別しなかったのが誤り。

| 指標名 | 値 | 分子 | 分母 | 単位 |
|---|---|---|---|---|
| `rightsBlockedDraftItems` | **191** | 出典が権利未確認だったdraft **item** | N3文法76＋N2文法15＋オノマトペ100 | item |
| `sourceProximityViolations` | **102** | 原本との類似度0.6以上だった **例文** | N3 152＋N2 24＋オノマトペ200＝376例文 | 例文 |

- 191は「権利未確認により公開できない状態だったitem数」
- 102は「そのうち、実際に書き直しが必要だった例文数」
- **191件すべてが102件の書き直しを必要としたわけではない**（1itemに例文2本、書き直しは平均0.53本）

**2026-07-28のCEO確認により、rightsBlockedDraftItemsは 191 → 0 になった**
（3ソースすべて `teacher_created_confirmed`）。

## 報告時のルール

1. 数値を出すときは**指標名・分子・分母・単位**を書く
2. 「完成」と言うときは、上の5段階のどれかを明示する
3. 「staging反映済み」と言うときは、上の5種別のどれかを明示する
4. 曖昧な数値を次の集計の入力にしない
