対象: `vocab-N3.json`（100問）・`vocab-N2.json`（100問）= 計200問
観点: 複数正解 / 正解の妥当性 / 誤答の質 / 語尾・長さの手がかり / 中国語の自然さ / 日本語の自然さ / 難易度整合 / 解説の正確性

## 総評

**そのまま3名の有料学習者に出せると判断できるのは 174/200（87%）。即修正が必要なのは 26問（13%、P0=2・P1=24）。**

ただし「出せる」と「実力を測れる」は別で、**200問すべてに共通する構造的な弱点**がある。

> 誤答（distractor）が意味的に競合していない。
> `src/lib/aiLesson/course/adventure/vocab/vocabQuestions.ts` を読むと、
> - reading の誤答 = `perturbReading()`（同じ母音の子音を1文字入れ替え）→ 実在しない仮名列
> - orthography / context / meaning の誤答 = 同レベルからのランダム抽出（意味・品詞・字形の制約なし）
> - usage の誤答 = 他語のコロケーションをそのまま流用
>
> 結果として、多くの問題が「語を知らなくても消去法で解ける」。正答率は実力より高く出る。パイロット中に正答率だけを見て「N2は簡単すぎた」と判断しないほうがよい。

## P0（即修正）

### P0-1. 複数正解 — 「学习」に対して 勉強 と 学習 の両方が正しい

| 項目 | 内容 |
|---|---|
| questionId | `vocab:勉強:べんきょう:confusable`（vocab-N3.json） |
| sourceWord | 勉強 \| べんきょう |
| 設問 | 「学习」という意味の言葉はどれですか。／ 表示「学习」的词是哪个？ |
| 選択肢 | **勉強（正解）** / 学習 / 練習 / 青い |

**何が問題か**
`学習` の中国語訳は `学习（有计划地学）` で、括弧を外せば「学习」そのもの。中国語話者にとって 勉強 と 学習 はどちらも「学习」であり、正解が2つある。しかも 学習 は 勉強 の `confusableSurfaces` に明示登録されている（`content/coreBatch01.ts:55`）ため、この組み合わせは必ず出る。

**なぜ漏れたか（根本原因）**
`vocabQuestions.ts:216` の複数正解ガードが **訳文字列の完全一致のみ**:
```ts
.filter((o): o is VocabOriginalContent => !!o && o.glossZh !== c.glossZh);
```
`'学习（有计划地学）' !== '学习'` が成立してしまい、素通りする。

**どう直すべきか**
1. 即応: 勉強 の `confusableSurfaces` から `学習` を外す（`練習` は残してよい）。
2. 恒久: ガードを「括弧・区切りを除いた語義集合の重なり」で判定する。
3. または confusable の設問文を訳そのままではなく `senseNoteZh` 付きで出す。

**波及範囲（重要）**
同じガードの穴を全語彙バンク（1,980語 / 736語に混同語登録）に当てて調べたところ、**同種の「複数正解になりうる混同語ペアが36組**存在した。サンプル100問にはたまたま1組しか出ていないが、実際の出題プールは N3で10,341問。パイロット中に別の複数正解が出る可能性が高い。特に危険なもの:

| 見出し語 | 訳 | 混同語 | 訳 |
|---|---|---|---|
| 少し | 一点；稍微 | ちょっと | 稍微；一点 |
| 持つ | 拿；带着 | 取る | 拿；取 |
| 後 | 之后；后面 | 後ろ | 后面 |
| 前 | 前面 | 先 | 前方；前面 |
| 並ぶ | 排队；排列 | 並べる | 排列；摆放 |
| 休み | 休息；假期 | 休む | 休息；请假 |
| 洗う | 洗 | 浴びる | 淋；洗（淋浴） |
| どうも | 实在；非常 | とても | 非常 |
| いかが | 如何（礼貌） | どう | 怎么样；如何 |

→ **パイロット前に confusable 観点だけでも全ペアを機械チェックすることを推奨。**

### P0-2. 日中同形異義語の誤訳 — 「平日」

| 項目 | 内容 |
|---|---|
| questionId | `vocab:平日:へいじつ:usage`（vocab-N3.json） |
| sourceWord | 平日 \| へいじつ |
| wordGlossZh | 平日；工作日 |
| explanationJa | 平日は仕事で忙しいです。 |
| explanationZh | **平日因为工作很忙。** |

**何が問題か**
中国語の「平日」は *平时・平常* の意味で、**「工作日（月〜金）」ではない**。訳文「平日因为工作很忙」は中国語話者には「普段は仕事で忙しい」としか読めず、日本語「平日＝土日祝以外の日」という肝心の意味が伝わらない。さらに `wordGlossZh` が「平日；工作日」と**誤解を招くほうを先頭に置いている**。日本語側の `wordExplanationJa`（土曜・日曜・祝日ではない日）は正しいので、中国語側だけが誤り。
これは中国人学習者が最も間違えやすい同形異義語の一つで、このまま出すと**逆の理解を刷り込む**。

**どう直すべきか**
- `wordGlossZh` → `工作日（周一到周五）` に一本化（「平日」を削除）
- `explanationZh` → `工作日因为工作很忙。` または `周一到周五因为工作忙。`
- あわせて「日本語の『平日』＝中国語の『平日』ではない」という注記を入れると価値が高い

※サンプル内で「中国語訳＝日本語表記が同字」の語は41語あるが、実際に意味がずれる同形異義語は `平日` のみだった（祖母・通勤・将来・数字などは括弧注記で担保できている）。

### P1-A. usage観点10問中9問 — 正解の選択肢にだけ見出し語が入っている（知識ゼロで正解可能）

設問は「「以降」を使う言い方はどれですか。」で、選択肢は他語のコロケーションをそのまま流用しているため、**見出し語が入っている選択肢を選ぶだけ**で必ず正解する。日本語をまったく読めなくても100%当たる。

| `vocab:辛い:つらい:usage` | 辛い | 仕事が**辛い** | 用事を済ませる / 範囲が広い / 信頼を得る |

| `vocab:ちゃんと:ちゃんと:usage` | ちゃんと | **ちゃんと**並べる | 電車に間に合う / うっかり忘れる / 商品が届く |
| `vocab:タイプライター:タイプライター:usage` | タイプライター | **タイプライター**を使う | ゲームをする / 日本語が上達する / 生き物を育てる |
| `vocab:市民:しみん:usage` | 市民 | **市民**が集まる | 試験に関する / まず最初に / スーパーに寄る |
| `vocab:食料品:しょくりょうひん:usage` | 食料品 | **食料品**を買う | 体重が増える / 講義を受ける / 情報を共有する |

（`vocab:平日:へいじつ:usage` も同じ構造だが P0-2 で計上）

**どう直すべきか**
usage の出題形式そのものを変える必要がある。案:
1. **共起相手を選ばせる**: 「＿＿＿の場所」で 公共 / 公開 / 公式 から選ばせる（見出し語を選択肢に置かない）
2. **正誤判定型（JLPT本番の用法問題に近い）**: 見出し語を4つの文すべてに入れ、正しく使えている文を選ばせる
3. 上記が作れない語は **usage観点を出さない**（`vocabQuestions.ts` の設計方針「作れなければその観点は出さない」に合わせる）

※ タイプライター（`vocab:タイプライター:タイプライター:usage`）は形式以前に、有料N3対策の出題語として現代性がない。

## P3（好みの範囲）— 23問

- **中国語訳と日本語が同字で、meaning問題がほぼ自明（6問）**: `近代`（N3/N2の2問）`方向``通勤``主語``部分`。「「部分」の意味はどれですか → 部分」は問題として成立していないに等しい。
- **語レベルタグの疑い（4問）**: `直ちに`（N4扱いだが実質N2）`半ば`（N4）`ママ`（N4）`四季`（N4）。難易度が語レベルから機械的に決まる（`vocabQuestions.ts:114`）ため、体感難度とずれる。
- **現代性の低い語（1問）**: `背広`（解説で「今は『スーツ』」と補足済みなので実害は小）。
- **解説の細かい正確性（1問）**: `vocab:火曜日:かようび:meaning` —「一週間の二番目の曜日」。日曜始まりの暦では三番目。「月火水…の順で2番目」と書くほうが安全。
