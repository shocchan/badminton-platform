## 2. 直したこと

### 2-1. 街イラスト（`AdvMapLandmarks.tsx`）

平面アイコン → **空・遠景の山なみ・地面・前景を持つ風景シーン**（16:11）。

- `MapTone` 8種（dawn / meadow / forest / water / stone / sunset / sky / night）で
  地域ごとに時間帯と気候を変える。**形だけ変えても小さく描くと差が消える**ため
- 17種すべて自作SVG。外部IP・既存ゲーム素材は不使用。文字は描かない（翻訳できないため）
- 霧を 0.72 → **0.5** に薄めた。濃いと未解放地域がどれも同じ白い板になり、
  「この先に何があるか」が想像できない＝行きたくならない
- 一覧表示用の小アイコンは従来のまま残した（風景を描くには小さすぎるため）

### 2-2. 情報の並べ替え（`AdvAdventureMap.tsx`）

上から順に「今どこ → だから今日は何をする → 攻略状況 → 各地域の詳細」。

1. **ヒーロー帯** — 現在地のイラストを背景に、章 / 現在地 / 鍛える力 / 目的地 / 全体進捗 / 次の目的地
2. **今日の一歩カード＋Primary CTA を地図より上へ**（原則16）。次のstep名も名指しする
3. ルート切替 — タブ名だけでは違いが分からないので一言hintを追加
4. **冒険の道** — 章の見出しで区切った縦ルート。攻略済みは実線＋緑＋✓、
   現在地は青の点線＋脈動＋「私」と先生、次の目的地は琥珀、未解放は霧＋錠前。
   道は `<li>` 全体を貫かせ、地域カードを開いても途切れない
5. **地域カード** — 行の外・画面幅いっぱいに出す（細い右カラムだと文もボタンも潰れる）
6. 開いた時点で**現在地のカードが開いている**。ルートを切り替えると現在地へ戻る
7. 開いたら現在地まで自動スクロール（20地域あると画面外になる）

### 2-3. 行き止まり0（原則15）

`MapRegion.action` を新設し、UI側で分岐を増やさずCTAを必ず1つ出す。

| 地域の状態 | CTA | 行き先 |
|---|---|---|
| 攻略済み | 復習で維持する | `onOpenReview` |
| 現在地（模試） | ミニ模試を受ける | `onOpenMock` |
| 現在地（会話） | AI会話を始める | `onStartConversation` |
| 現在地（その他） | 今日の冒険でここを進める | `onStartToday` |
| 次の目的地 / 未解放 | 今日の冒険を進める | `onStartToday` |

- **先の地域からは会話・模試へ飛ばさない。** いまの週の会話が出て話が噛み合わないため
- 復習0件・AI会話未開放のときは、その行き先へ飛ばさず今日の冒険へ倒す
  （押しても何も起きない状態を作らない）
- 上部の主要CTAと現在地カードのCTAが**同じ文言にならない**ようにした（テストで検出）

### 2-4. 誠実さ（原則13）

- 現在地の定着率を **0%固定 → 実測値**（`masteryProgressPct`）
- 「ここまで」も台帳の実績を言う（定着50%なのに「まだ攻略していません」を解消）
- 「次にすること」は攻略条件の丸写しではなく `computeMastery` の
  「別の日にあと1回、80%以上（未出問題を含む）」
- 会話レイヤーは測っていないので現在地でも**バーを出さず「未判定」**
- 未解放の地域には「どうすれば開くか」を必ず持たせた

### 2-5. 色調の重複防止

stage構成は診断結果で変わるので対応表だけでは重複を防げない。
`spreadTones` で並べ終えてから隣接の色調をずらす（テストで固定）。
