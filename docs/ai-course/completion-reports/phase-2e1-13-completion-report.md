### timeout根本原因（§3）

**アプリ側の不具合ではなく、私（Claude）の自動操作の組み方が原因だった。**

- 練習は1語あたり `card → quiz → assess` の3フェーズで、3語＝約9インタラクション。
  これを1回のCDP `Runtime.evaluate` にまとめると45秒上限を超えて必ずtimeoutする。
- 今回は**1コール1操作**に分割したところ、全ステップが1〜2秒で完了し**timeoutは0回**。
- 手動操作での再現: なし（アプリのCTAはdisabledで止まらず、完了イベントも正常に発火）。
- 副次的に判明: React再render直後の同一コール内で次のボタンを探すと `disabled` のままで
  見つからないことがある（選択→確定の間）。**コールを分ければ解消**。

## 2. 実機検証で見つけた重大な欠陥（修正済み）

### 「今日のことば」が間隔反復に接続されていなかった

Step4は「今日まよったことばは、忘れかけるころにもう一度出てきます」と案内するのに、
**復習予定が0件**だった。原因は今日のことば（DailyFlowView）がクイズ結果・自己評価を
復習スケジュールへ一切書いていなかったこと。2E-1.10では復習画面側だけが接続されていた。

修正: クイズの正誤（誤答→翌日／正解→7日後）と自己評価（まだ不安→翌日、覚えた→予定は消さない）を接続。
実機再検証で **誤答した「名前」に翌日（2026-07-29）の予定が生成**されることを確認。
回帰テスト3件を追加。

これは**学習ループが閉じているかどうかの中核**であり、ユニットテストでは検出できず、
実機で完走したからこそ見つかった。

## 3. CEO指示の視覚設計（見やすく・視線が動きやすく・イメージしやすく）

新規: `LearningIllustrations.tsx`（インラインSVGのみ・外部ライブラリ0・画像リクエスト0）

| 追加 | ねらい | 置いた場所 |
|---|---|---|
| ステップイラスト4種（方位磁針／カードと虫めがね／吹き出し／カレンダーとチェック） | 各ステップが何をする所か絵で分かる | Journey各ステップ見出し |
| ステッパー（番号・✓・接続線・現在は塗り＋リング） | 今どこか・あといくつか | Journey上部 |
| 段階表示「見る › ためす › ふりかえる」 | 「何問目か」だけでは見えない、語の中の今の一歩 | 練習画面 |
| 結果の横棒グラフ | 今日の結果を見て分かる | Step4・完了画面 |
| 復習タイムライン（今日→明日→3日後→7日後） | 「また戻ってくる」を時間軸で示す | Step4・完了画面 |

設計方針（テストで担保）:
- **図は理解の補助であって唯一の情報源にしない。** 件数・ラベルは必ず文字でも読める
- 0件の項目は棒を描かない（0を強調して落ち込ませない）／0件の予定日は薄く描くが存在は示す
- 色だけに依存させない（済み=✓・現在=塗り＋リング・未来=薄い丸と形も変える）
- アニメーションは `prefers-reduced-motion` 準拠の200〜500msのみ

実機で見て直した点（見た目の粗さ）:
1. `h-18` は存在しないユーティリティで絵が潰れていた → 比率保持の幅指定へ
2. タイムラインの「今日」列だけ構造が違い点とラベルの高さがずれていた → 全列同一構造へ
3. 共通viewBoxの余白で絵が小さく見えた → 図形に合わせたviewBoxへ
4. まとめの絵の小さな装飾点がノイズだった → カレンダー＋大きなチェックのみへ
