# 生徒がPCからログインできなかった件と、配るときの案内文

日付: 2026-09-01
きっかけ: サマーさんが「PCからログインしようとしたら、崩れた画面になる」と連絡

---

## 何が起きていたか

学習アプリはJavaScriptで画面を描く。ブラウザがそのプログラムを実行できないと、
**エラーも出ずに何も起きない**。本人には「壊れている」としか見えない。

本番のプログラムを調べた実測:

| 項目 | 実測 |
|---|---|
| 読み込み方 | `<script type="module">` のみ → **Chrome 61以降が必要** |
| `?.` の使用 | 55箇所 → **Chrome 80以降** |
| `??` の使用 | 71箇所 → **Chrome 80以降** |
| `\|\|=` `??=` | 19箇所 → **Chrome 85以降** |
| 古いブラウザ向けの控え | **無かった** |

つまり **Chrome 85相当より古いブラウザでは、1行も実行されない。**

見えていた画面（`kb-prerender`）は、検索エンジン向けに置いてある素のHTML。
本来はアプリが起動した瞬間に消えるが、起動しないので残り続けていた。

**ログインページにはその素のHTMLすら無いので、完全な白画面になる。**
サマーさんが「ログインできない」と言ったのはここ。

### 中国でとくに起きやすい理由

- **微信（WeChat）の内蔵ブラウザ** … UAが `Chrome/53` を名乗る古いエンジン
- **360浏览器・QQ浏览器の「兼容模式」** … IE相当で描画する。中国の会社PCで普通に使われている
- 会社支給PCの古いブラウザ

サマーさんは「微信粘贴和直接打开都不行」＝**WeChat経由でも直接開いてもダメ**と回答。
つまりWeChatだけの問題ではなく、**ブラウザ本体が古い**可能性が高い。

---

## 直したこと（2026-09-01）

### 1. 古いブラウザ向けの控えを出す

`@vitejs/plugin-legacy` を入れ、`<script nomodule>` で読む
ES5版のプログラムを別に出すようにした。
新しいブラウザは `nomodule` を無視するので、**いまの利用者の読み込み量は変わらない**。

ビルド時間は 40秒 → 82秒になる。

### 2. それでも起動できなかったときに案内を出す

`index.html` に、**ES5だけで書いた**小さなスクリプトを置いた。
読み込みから6秒たっても画面が空なら、その場に案内を描く。

- 日本語ページなら日本語、`/zh` なら中国語
- Chrome / Edge で開く、360・QQは「極速モード」に切り替える、を具体的に書く
- それでもダメなら先生に連絡、といまのURLを出す

**白画面のまま放置される状態をなくすのが目的。**
プログラムが実行できない環境でも、この案内だけは出る。

## 配るときの案内文（そのまま送れる）

### 微信・LINEでURLを送るとき（中国語）

```
学习页面在这里 👇
https://study.kawabado.com/zh/ai-course/login

※ 请用 Chrome 或 Edge 打开（不要在微信里直接点开）
   在微信里的话，点右上角「⋯」→「在浏览器中打开」
```

### 日本語で送るとき

```
学習ページはこちらです 👇
https://study.kawabado.com/ja/ai-course/login

※ Chrome または Edge で開いてください
   （LINE・WeChatの中から開くと、うまく表示されないことがあります）
```

### うまく開けないと言われたとき（中国語）

```
不好意思，让你遇到这个问题了 🙇

请试试下面的方法：

1. 用 Chrome 或 Edge 打开（不要用微信里的浏览器）
2. 如果用的是 360浏览器・QQ浏览器，请切换到「极速模式」
   （地址栏右边有个小图标，点一下可以切换）
3. 把浏览器更新到最新版本

还是不行的话，请把画面截图发给我，我来查。
```

3. **画面を撮ってもらう** … 白画面なのか、素のHTMLが出ているのかで原因が分かれる
