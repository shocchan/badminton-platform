# Phase 4 — 教材間の接続（2026-09-10）

文法だけを孤立させない。**分野 → 語彙 → 文法 → 例文 → 読解 → 聴解 → 産出** をIDで辿れるようにした。
教材の本文は1文字も変えていない。既存IDをそのまま使う。

## 作ったもの

| ファイル | 役割 |
|---|---|
| `knowledge/crossLinks.ts` | 辺の構築（`buildCrossLinks`）・経路（`learningPath`）・文法の関連（`linksOfGrammar`）・QA（`crossLinkCoverage`） |
| `knowledge/crossLinksLoad.ts` | 本番教材（文法552・語彙4,915・読解/聴解780）から索引を1回だけ作る |
| `knowledge/crossLinks.test.ts` | 合成データで辺の作り方を固定＋本番教材の全体QA |

## 辺の種類と根拠

辺は **explicit**（教材が自分で持つリンク）と **derived**（本文に実際に出ていることから機械で引いた）に分け、
derived は根拠を `via` に残す（例: `example:資料`／`text:を余儀なくされ`）。あとから人が見て外せる。

| 層 | explicit | derived | 導出の根拠 |
|---|---|---|---|
| 文法 → 語彙 | 480（vocabularyLinks） | 2,299 | 例文に語が文字どおり出る（2文字以上・漢字を含む語だけ） |
| 文法 → 読解/聴解 | 59（N1 の knowledge） | 6,639 | 本文に文法の芯（3文字以上）が出る。**級を超えない**（N5 の本文に N1 文法は当てない） |

Phase 2-1 の教訓（例文由来のタグは誤りが多かった）を踏まえ、**間違った辺を作らない**側に倒した:
かなだけの短い語・1文字の語・2文字以下の文法の芯では本文照合しない。

## 経路の例（work × requesting、N2 の学習者）

```
語彙   受付・依頼・願書・受け付ける・取り消す
文法   〜てもらう ／ 〜を（目的語） ／ 〜ことから ／ 〜ように言う ／ 〜ようになります
例文   市役所の受付で書き方を教えてもらいました。
読解   n3r-long-07 / n3r-mid-02 / n3r-long-11 / n3r-long-12 / n2r-theme-11
聴解   n2l-point-12 / n3l-point-05 / n2l-int-15 / n3l-task-02 / n3l-int-05
産出   お店や病院で頼んだことを話す（advconv-…）
```
- 学習者の級より上の教材は入らない（N1 の教材・文法は N2 の経路に出ない。テストで固定）。
- その級で使える語が無ければ**空のまま返す**（無いものを在るように見せない）。
- 文法の並びは「経路の語が例文に出る数」＋「学習者の級に近いほど加点」＋「場面の手がかり語（依頼・謝罪…）が practice に出れば加点」。
