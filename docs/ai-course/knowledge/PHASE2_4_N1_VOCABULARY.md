# Phase 2-4 — N1 語彙の監査と補完（2026-09-10）

N1 語彙は 317 語（batch 41〜46）だった。「N2 が 1,280 だから N1 も揃える」という件数合わせはせず、
**N1 の教材と N1 の文章に必要な語から逆算**して、足りない語だけ足した。

## 監査のやり方

1. **教材コーパスから逆算**: N1 読解30本の本文・N1 聴解38本の原稿・N1 文法150項目の例文から
   漢字語（2〜4字）と 漢字＋送り仮名 を機械で抜き（3,675 種）、既存バンク 4,697 語に無く、
   かつ辞書索引（JMdict 由来）に有るものを候補にした（374 種）。
2. **論説・書き言葉から逆算**: 社説・報告書・講演で使う抽象名詞／副詞／な形容詞／和語動詞／評価の形容詞を
   1,008 語列挙し、バンクに無いものを抽出（631 種。うち辞書索引に有るもの 476）。
3. 候補を人が読んで、N1 の「abstract / formal / written / workplace / synonym nuance」に当たるものだけ採用。
   **級は語ごとに判定**し、N1 教材に出ていても語自体は N2 相当のもの（事情・結末・箇所・引き継ぐ…）は
   `level: 'N2'` で入れた（N2 の学習者にも出す。N1 スコープは N5〜N1 全部を含むので N1 にも出る）。
4. 既存の品質ゲート `validate-vocab-content.ts` を通す（読み・品詞を辞書索引で照合、例文に見出し語、
   訳にかな混入なし、多義語には senseNoteZh）。**辞書索引に無い語は採用しない**（既存方針）。

## 監査で分かった、N1 の範囲外の問題（今回は直していない）

教材コーパスに出るのにバンクに無い語の上位は、**N1 語ではなく基礎語**だった:
必要(26)・理由(26)・自分(23)・意見(13)・手続き(13)・必ず(12)・想像(9)・事情(7)・方法(7)・予定(5)・存在(6)・示す(6)・過去(5)…

つまり N3〜N5 のバンクに、教材の本文で普通に使われる基礎語の抜けがある（starter batch 50〜 で「行く・見る」級は
埋めたが、抽象寄りの基礎語は未着手）。これは N1 の件数合わせとは別の話なので Phase 2-4 では手を付けず、
Phase 4（教材横断接続）で「本文に出るのに語彙項目が無い語」として一覧化し、級を判定して足す。
