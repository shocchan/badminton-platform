# Phase 5 — Business Japanese ＝ Practical Axis の一層（2026-09-10）

JLPT N1 の上位教材としては作らない。JLPT の教材をコピーもしない。
**知識項目（文法・語彙・読解・聴解）は共通のまま**、その上に「仕事の文脈」を別の層として載せた。

## 層の形（`knowledge/businessContext.ts`）

10 文脈: 敬語／社内のやりとり／報告・連絡・相談／電話／会議／メール・チャット／交渉／営業／面接／職場の文化

各文脈が持つのは **ID と文脈だけ**（教材本文を持たない。テストで `pattern`／`examplesJa` が無いことを固定）:

| 要素 | 中身 |
|---|---|
| `grammarIds` | 既存の grammarId。敬語は **N4 の既存項目**（お〜になる／お〜する／特別尊敬語・謙譲語／〜ております／〜させていただきます）をそのまま使う。N1 は をもって・べく・かねる・とはいえ・にしてみれば・ともなると・を踏まえて・ものと思われる… |
| `n2Categories` | N2 文法の既存分類（`n2Categories.ts` の formal／work）から自動で足す（手で N2 を選び直さない） |
| N3 層 | 同じ文脈を N3/N4 の既存文法で（〜ておく・〜てもらう・〜てしまう・〜ように言う・〜に比べて・〜に限り…）。N3 の学習者にも束が空にならない |
| `domains` / `situations` / `keywords` | 語彙を Practical Axis（work／money × 依頼・報告・交渉…）と文脈の手がかり語（電話・議事録・見積・志望…）で引く |
| `scenes` | 文脈ごとに会話場面 3 つ（N1 向け 2 ＋ N3 向け 1）。starter と使う grammarId。**AI会話ミッションの材料**（Phase 6） |

`businessPack(idx, context, level)` が Phase 4 の索引を使って、学習者の級以下だけで
文法・語彙（根拠付き）・読解・聴解・産出・場面の束を返す。
