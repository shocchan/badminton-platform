# Pilot 実機チェック（3名提供前の必須subset）

作成: 2026-07-30 ／ 所要: **iPhone 12分＋Android 8分＋読み上げ 10分＝合計約30分**
対象URL: `https://staging.badminton-platform.pages.dev/ja/ai-course`（中文で見るときは右上「中文」）

47項目の完全版は `physical-device-check-packet-20260730.md`。
こちらは**これが通らなければ3名に出せない**項目だけに絞ったもの。

## 事前準備（5分・1回だけ）

1. 招待コードを用意する（現在 有効な招待が1件・無制限で使える状態）
2. テスト用に**自分のメールアドレス**でサインアップする（本番の3名とは別のアドレスを使う）
   - サインアップ → メールに届く6桁コードを入力 → ホームが出れば準備完了
3. 端末を2台用意する（iPhone・Android）。**同じアカウント**で両方にログインする
   → これで「端末をまたいで進捗が引き継がれるか」を確認できる

記入方法: 各行の `[ ]` に `PASS` / `FAIL` / `SKIP` を書く。FAILは症状を一言添える。
スクリーンショットは `pilot-<端末>-<番号>.png`（例 `pilot-iphone-P07.png`）。
