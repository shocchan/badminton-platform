# 問題作成ガイド（新語・新文型を追加するときに読む）

更新: 2026-07-30（QP-3クローズ・G2/夜間監査の教訓を恒久化）

## cloze（穴埋め）の単一正解チェック
1. **連体修飾フレーム「＿＿＋名詞」は本質的に多義** — 名詞側を強く選ぶ語（例:「大事な＿＿」）にしない。
   動詞・助詞で意味が閉じるフレームを選ぶ（例:「駅で＿＿ります」）。
2. 例文を書いたら、pool内の同品詞語を機械的に当てはめて音読する。
   **1語でも自然に成立したら**: 例文を閉じたフレームへ書き換える／その語幹を
   `CLOZE_DISTRACTOR_UNSAFE`（assessQuestionEngine）へ理由コメント付きで追加。
3. どの誤答でも成立する開放フレーム（が主語のみ・時刻のみ・汎用を+ます）は
   `CLOZE_SUPPRESS` に入れてclozeを諦め、他のStage2次元で測る。
4. 追加後は必ず `quality.test.ts` の単一正解テスト＋目視で新規生成分を確認する。

## commonFormsJa（コロケーション）
- [0]=辞書形の自然な句・[1]=ます/ました形の文。対象語の語幹を必ず含める（unitCoverage.testが検証）。

## 対照問題（cognateContrastBank）
- 選択肢は**すべて文法的に成立**させ、意味・場面だけで単一正解にする。
- authorship='individually_authored_by_ai'・humanReviewed=false を維持（人手執筆と偽らない）。
