## 5. 学習品質

### 5-1. 語彙（実走7問・全問記録）

出た形式（1回の7問で6種類）: 漢字書き取り／語義選択／読み方／穴埋め／連語（コロケーション）／意味→語。**同じ形式ばかりで飽きる問題はない。**

良かった点（実測）:
- 正解後に「意味＋例文（日中対訳）＋他の選択肢がなぜ違うか」が必ず出る
- 例文が日本生活に密着（願書を郵送する／夜勤／部活／帰化の申請／制服を汚す）
- 反応 <1秒。誤答も錯題本へ自動登録

改善が要る点:
- **レベル不一致**: 会話目標・基礎帯の学習者に N2 の文字語彙が出た（「教頭」「願書」）。会話ルートの人が語彙バトルで出会う難易度が目標と噛み合っていない → P1-1
- 読み問題の誤答解説が「这是别的词的读音」（＝情報ゼロ）→ P2-3
- 内部ID `（vc-25-013）` が画面に露出 → **修正済み**
- 選択肢ボタンにアクセシブル名が付かない（スクリーンリーダーで無名ボタン）→ P2-4

「問題前に30秒プレビューを入れるか」への回答: **入れない方がよい。** 実走した限り、いまの「問題→正解→その場で学ぶ」は1問あたり体感10秒で、学びは誤答直後の解説に集約されている。プレビューを足すと「読むだけの旧教材」へ半歩戻る。代わりに**誤答解説の質**（上記P2-3）に投資すべき。

### 7. 言い直し・レポート

**P0-1（最重要）: レポート生成が本番で毎回失敗している。**

- 実測: `ai-lesson-report` → **HTTP 502 `{"error":"openai_error","status":400}`**（curl で単独再現）
- 影響: 画面は汎用フォールバックに落ち、`corrections: []` `naturalPhrases: []`。つまり **「次に直すこと」「言い直し素材」が1件も出ない**
- 範囲: 8/23 のEdge Function再デプロイ以降の**全セッション**（DB実測で5件すべて `corrections 0 / naturalPhrases 0`）。8/15〜8/19 のセッションには `naturalPhrases 2` 等が入っており、**以前は機能していた**
- 原因: OpenAI structured output の strict モードは properties を全部 required に入れることを要求する。中国語補助2項目が required から外れていた（同じ事故が 8/04 に `f011e44` で修正済みだったが、**そのコミットが別ブランチで、現行ブランチに入っていなかった**）
- 対処: 修正＋**ソースを読んで「properties ⊆ required」を機械で固定する回帰テスト**を追加（`reportSchemaStrict.test.ts`）
- ⚠️ **Edge Function のデプロイは production 変更のため未実行＝CEO承認待ち**

理想形（できたこと1／次に直すこと1／もう一度言ってみる1）に対する現状:
- 「今天，你变得能做到的事」1件＋「下次复习: 日付」は出る＝**認知負荷は低い**
- ただし中身が汎用文なので「具体的」「learnerの実発言を反映」を満たさない
- レポート復旧後は、実発言ベースの corrections が最大2件・naturalPhrases 最大2件という上限設計なので、理想形にそのまま合致する
