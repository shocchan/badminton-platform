## 0. 準備（5分）

自分用のアカウントを作ります。**自分が普段使っているメールアドレス**を使ってください
（招待コードはそのアドレスでしか使えません。8桁の数字がメールで届きます）。

```bash
cd ~/badminton-platform
node scripts/ai-course/issue-pilot-invites.mjs \
  --learner A --email <自分のメール> --expires 2026-08-31 --confirm
```

画面に出る `CODE: PLT-XXXX...` を控えてください（**この1回しか表示されません**）。

## 1. 入るところ（学習者と同じ体験）

- [ ] 上のURLを**スマホ**で開いた
- [ ] メールアドレスと招待コードを入れた
- [ ] メールに届いた**8桁**の数字を入れてログインできた
- [ ] 迷わず入れた（迷ったなら、どこで迷ったかメモ）

## 2. 最初の設定

- [ ] 「何のために日本語を勉強しますか」が出た
- [ ] N2合格 / N3合格 / 会話力 / 両方 から選べた
- [ ] 試験の予定日を入れられた
- [ ] 1日に使える時間（5分 / 15分 / 30分）を選べた
- [ ] **翔子先生か悠斗先生を選べた**
- [ ] 選んだ先生が、このあとの画面にちゃんと出ている

## 3. 診断（今の実力を測る）

- [ ] 診断が始まった
- [ ] 分からない問題を飛ばせた
- [ ] 診断のあと「あなたの現在地」が出た
- [ ] **「レベルを下げられた」と感じなかった**
      （N2志望なら、N3が出てきても「N2へ行く途中」と書いてあるはず）

## 4. ホーム（毎日ここを開く）

- [ ] 「N2合格まであと◯日」が出ている
- [ ] **「現在地：◯◯」**が出ている
- [ ] 先生が「今日は◯分。まず〜から始めましょう」と言っている
- [ ] 今日やることが**一覧で見えている**（1〜5など）
- [ ] **押すボタンが1つだけ**になっている
- [ ] 「今日は何をしよう」と迷わなかった

## 5. 今日の冒険をやってみる

- [ ] ボタンを押したら、文法の説明が出た
- [ ] 説明のあと「バトルに挑む」が出た
- [ ] 問題が出て、答えると**正解／不正解と理由**が出た
- [ ] 誤答それぞれに「なぜ違うか」が書いてあった
- [ ] 問題が難しすぎ／簡単すぎでなかった
- [ ] 中国語の説明が自然だった

## 6. AI会話（マイクを使います）

- [ ] 会話のステップに進めた
- [ ] マイクの許可を出せた
- [ ] **選んだ先生の声で話しかけてきた**
- [ ] 自分が話した内容を聞き取ってくれた
- [ ] 1〜2往復できた
- [ ] 会話のあと**レポート**が出た
- [ ] 「言い直し」ができた
- [ ] 復習に登録された

> 声が出ないときは、①ブラウザを最新に ②イヤホンを外す ③Safari↔Chromeを変える を試してください。

## 7. 今日を終える

- [ ] 全部終わると「今日の冒険を締めくくる」が出た
- [ ] **今日の手ごたえ**（どの力を何問できたか）が出た
- [ ] **次の冒険**がいつか書いてあった
- [ ] 行き止まりにならず、次に何をすればいいか分かった

## 8. 冒険マップ

- [ ] 上の「冒険マップ」を押した
- [ ] **地図が出た**（文字だけの一覧ではない）
- [ ] 自分の**現在地が1つだけ**光っていた
- [ ] まだ行っていない場所に**霧**がかかっていた
- [ ] 地域を押すと「何の力を鍛えるか」「次にすること」が出た
- [ ] 「今日の冒険を始める」で戻れた
- [ ] スマホで**横スクロールが出なかった**

## 9. 週のまとめ・先生レッスンの準備

- [ ] ホーム →「ほかの学習を見る」→「今週のまとめ」が見られた
- [ ] まだ記録が無いところは**「未判定」**と書いてあった（0%ではない）
- [ ] 「先生レッスンの準備」に**3件まで**出ていた
- [ ] その3件は、自分がレッスンで話したい内容として妥当だった

## 10. 先生を変える

- [ ] ホーム →「ほかの学習を見る」→「案内の先生を変える」で変更できた
- [ ] 変更後、**AI会話の声が変わった**
- [ ] 画面の先生の名前・絵も変わった
- [ ] ページを再読み込みしても選んだ先生のままだった

## 11. 中国語表示

- [ ] 右上で「中文」に切り替えた
- [ ] 主要な画面が中国語になった
- [ ] 不自然な中国語や、日本語が混ざっている箇所がなかった
