## 0. これは何か

中国語話者（主に中国人日本語学習者）向けの、AIで進めるJLPT対策＋日本語会話の
オンライン学習サービス。個人事業。運営者は1人（日本語講師）。

売り方は3つ。
| 商品 | 価格 | 中身 |
|---|---|---|
| 60分AIパス | 600円 | 累計60分のAI学習。人間の講師なし |
| 1か月プラン | 未確定 | 30日間のAI学習。人間の講師なし |
| 半年伴走コース | 100,000円 | 6か月。AI学習＋人間講師の個別レッスン |

いま実際に売ろうとしているのは **半年伴走コース**。まず運営者自身が
生徒と同じ画面で通しで使ってみて（オーナーパイロット）、問題を洗い出している最中。

**現段階はステージング環境のみ。本番公開は一度もしていない。実課金もしていない。**

## 1. いまの構成

```
ブラウザ（React SPA）
   ↓ 同一オリジン
Cloudflare Pages + Worker（/api/ai-course/*）
   ├─ Cloudflare R2（非公開バケット）… 教材の本体
   └─ Supabase（staging専用プロジェクト）… 認証・学習者・利用権の台帳
```

- ステージングURL: `https://ai-course-staging.pages.dev`
- 本番（`kawabado.com`）へは未反映。ブランチ `feature/ai-course-secure-runtime-review` に隔離
- Supabase は本番と**別プロジェクト**（本番データに触れないため）

### 教材の守り方（この設計の中心）

「お金を払った人だけが、買った期間だけ教材を使える」を成立させるため、
教材をブラウザ側へ一切置かない構成にしてある。

- 教材（問題 約21,000問・読解・聴解・文法解説・会話ミッション）は **R2の非公開バケット**。
  公開URLは無い。ファイル数 1,833・約75MB
- ブラウザが受け取るのは「いま解く問題」だけ。**正解は送信前のデータに含まれない**（採点はサーバー）
- 聴解音声は短命の署名つきURLでのみ再生できる
- 問題キーは擬似化してある（どの問題かを外から数えられない）
- 公開ビルドに教材が1バイトも混入していないことを、毎回スクリプトで計測（現在 **0**）

## 2. 動いているもの（ステージング実測済み）

### 生徒アカウント
- 先生用の発行画面（`/ja/ai-course/issue`）から、メール・登録名・開始日・期間を入れて発行
- 生徒は **ログインID（例 `MN-4K7Q`）＋ 6文字の半角英数字パスワード** でログイン
- 大文字小文字を区別しない。全角で打っても通る。ハイフン・空白は無視
- パスワードは自前DBに平文で持たない（Supabase Authのハッシュのみ）
- 失敗理由を出し分けない（IDの存在を推測させない）／5回失敗で一時ロック（自動解除）
- パスワード再設定・ログインID問い合わせはメール経由。応答は登録の有無で変わらない
- ログイン周りの実HTTP検証 **14項目 PASS**

### 学習
- ログイン → 利用案内 → 目的・目標レベル・受験日・学習ペース・先生・相棒を選ぶ
- 現在地診断12問（**選択式のみ。日本語の入力なし**）→ 攻略ルート生成
- 「今日の冒険」に今日やること3つが出る（例：単元のことば／聴解トレーニング／言い直し）
- 問題バトル（サーバー出題・サーバー採点・間違いは日中2言語で解説）
- 読解・聴解（音声つき）
- ミニ模試（短時間版／本番時間版）
- 冒険マップ（進捗の地図表示）
- 教材配信・採点・音声の実HTTP検証 **35項目 PASS**

### 利用権（お金の話）
- 半年コースは**期間制**。台帳（購入→利用権）に記録し、**サーバーが毎回引き直す**
- 実測：利用権のないアカウントが「持っている」と偽って要求 → **403で拒否**
- 60分パスは時間制：購入から7日以内に開始 → 開始してから24時間の中で60分

### 品質
- 自動テスト **2,123本 PASS**
- 教材の公開露出 **0**

## 3. 動いていないもの（重要）

### ① AI会話・学習レポートが動かない
このコースの中心機能。Supabase Edge Functions が**未デプロイ**。
実際に叩くと全部404：

```
ai-lesson-chat     404   ← AI音声会話
ai-lesson-report   404   ← 学習レポート
ai-lesson-token    404   ← 音声セッションの発行
ai-course-checkout 404   ← 決済
ai-course-auth     404   ← 旧認証
```

つまり **「翔子先生とAI音声で毎日話す」という商品の核が、まだ一度も動いていない。**

### ② 冒険マップの島が行き止まり
マップの島（カタリ港・ユカリの森 等）をタップすると
「この機能は現在、冒険モードへ移行中です」と出て何もできない。

理由：これらの画面は教材を静的に持つ旧実装で、教材が公開ビルドに混入するため
**意図的に公開ビルドから外してある**。外した先の導線が残ってしまっている。

同じ理由で使えない画面：
- ことば図鑑（VocabularyHub）
- しくみラボ（FoundationLabShell）
- 第1章アドベンチャー（Chapter1AdventurePanel）
- N3単元エリア（N3AreaPanel）
- N2文法クエスト（N2GrammarQuestPanel）

「今日の冒険」の1つ目も同じ穴に落ちていたので、そこは問題バトルへ繋ぎ替え済み。
**マップからの入口は未対応。**

### ③ 学習の進捗がサーバーに保存されていない
進捗はブラウザのlocalStorageと学習者レコードに書いているが、
**サーバー正準の進捗台帳（開放ステージ・累計学習秒・解答履歴）は未実装**。

いまの影響：
- 端末を変えると進捗が引き継がれない可能性がある
- 学習時間の計測がブラウザ申告のまま（60分パスの残り時間を正確に守れない）

半年コース（期間制・時間の上限なし）では実害が小さいが、
60分パスを売るなら必須。

### ④ 決済が動かない
Stripe未接続。いまは「先に申し込み → 支払い方法をメールで案内」の運用前提。
半年コースは元々そうなので当面は困らない。

### ⑤ 本番未反映
本番 `kawabado.com` には一切出していない。ブランチもmainへ未マージ。

## 5. これまでに見つかった不具合の傾向

運営者が自分で通しで使ったら、1日で以下が出た。

1. 発行したアカウントが旧コース画面に着地していた（新機能が有効化されていなかった）
2. 半年コースの利用権が、書き込み先テーブルを間違えていて**1件も作られていなかった**
3. 利用権の判定を**ブラウザの申告任せ**にしていた（払っていない人が通せる状態）
4. 料金ページの記載が実装より甘かった
5. 端末の「戻る」がコースの外へ出てしまう
6. 診断のあと「準備をしています…」から進まない
7. 選ばせた相棒キャラが、そのあと一度も出てこない
8. 今日やること1つ目が行き止まり

**傾向：個々の部品は作ってあるが、繋がっていない／繋ぎ間違えている。**
通しで触るまで誰も気づけなかった種類のものが多い。

### Q2. 冒険マップの島の行き止まりをどうするか

半年コースだけなら後回しにできる。60分パスを売るなら先にやる必要がある。

**いきなり問題バトル**へ繋いだ（間違えたら解説が出る）。
