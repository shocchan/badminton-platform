# 実生徒アカウントの発行手順と案内文

2026-08-04。Paid Student Ready: YES（staging）。

---

## A. 先生の作業（5分）

### 1. 発行画面を開く

```
https://ai-course-staging.pages.dev/ja/ai-course/issue
```

合言葉はここで確認する（チャットやメールに貼らない）:

```bash
cat ~/.ai-course-admin-passphrase.txt
```

### 2. 入力する

| 項目 | 入れるもの |
|---|---|
| 合言葉 | 上で確認したもの |
| 生徒のメールアドレス | **生徒本人が受け取れるアドレス**（パスワード再設定に使う） |
| 登録名 | 生徒の呼び名。本名でなくてよい |
| 用途 | 実際の生徒（paid_student） |
| 利用開始日 | 受講を始める日 |
| 期間 | 6 |

### 3. 出てきたIDとパスワードを渡す

**この画面に一度だけ**表示される。再表示はできない。
「文面をコピーする」を押して、生徒へそのまま送る。

送る手段は、その生徒と普段使っている連絡先（WeChat等）でよい。
**メールで送る必要はない**。メールアドレスはパスワード再設定にだけ使う。

### 4. 生徒が入れたか確認する

生徒から「入れた」と連絡が来たら完了。
入れないと言われたら、同じメールアドレスで**もう一度発行する**。
ログインIDは変わらず、パスワードだけ新しくなる。学習内容は消えない。

---

## B. よくある問い合わせと答え

| 生徒が言うこと | 対応 |
|---|---|
| パスワードを無くした | 同じメールで再発行。IDは変わらない |
| ログインできない（何度も失敗） | 5回失敗で15分ロック。時間を置くか、再発行すれば解除される |
| 大文字と小文字がわからない | どちらでも入る。全角で打っても入る |
| 別のパソコンで続きをやりたい | そのままログインすれば続きから始まる |
| 進捗は消えますか | 消えない。受講終了後1年間保存 |

## C. 生徒へ送る案内文（日本語）

```
AI日本語伴走コースへようこそ。

学習ページ：
https://ai-course-staging.pages.dev/ja/ai-course/login

ログインID：（ここに貼る）
パスワード：（ここに貼る）

■ 使い方

1. 上のリンクを開きます
2. ログインIDとパスワードを入れます
   ・パスワードは半角の英数字6文字です
   ・大文字と小文字は区別しません。全角で打っても入ります
3. 「はじめる前に」を読んで「はじめる」を押します
4. 目的・目標レベル・学習ペース・先生・相棒を選びます
5. 現在地診断（12問）を受けます
   ・選ぶだけです。日本語を入力する必要はありません
   ・わからない問題は「わからない」で大丈夫です
6. あなた専用の攻略ルートができます
7. 毎日「今日の冒険」に出ている3つを進めてください

■ お願い

・SafariかChromeで開いてください（アプリの中のブラウザは音が出ないことがあります）
・AI会話のときはマイクを許可してください
・イヤホンをおすすめします

■ 困ったとき

・パスワードを忘れた → ログイン画面の「パスワードを忘れた方」
・ログインIDも忘れた → ログイン画面の「ログインIDも忘れた方」
・それでも入れない → 私に連絡してください。すぐに作り直します

学習の記録はサーバーに保存されます。
別のパソコンやスマホからログインしても、続きから始められます。
```

## D. 生徒へ送る案内文（简体中文）

```
欢迎参加AI日语伴走课程。

学习页面：
https://ai-course-staging.pages.dev/zh/ai-course/login

登录ID：（在这里粘贴）
密码：（在这里粘贴）

■ 使用方法

1. 打开上面的链接
2. 输入登录ID和密码
   ・密码是半角英文数字6位
   ・不区分大小写。用全角输入也可以登录
3. 阅读「开始之前」，然后按「开始」
4. 选择目标、目标等级、学习节奏、老师和伙伴
5. 进行当前水平测试（12题）
   ・只需选择，不需要输入日语
   ・不会的题目选「不知道」就可以
6. 系统会生成属于你的攻略路线
7. 每天完成「今天的冒险」里的3件事

■ 请注意

・请用Safari或Chrome打开（App内置浏览器有时无法播放声音）
・AI会话时请允许使用麦克风
・建议戴耳机

■ 遇到问题时

・忘记密码 → 登录页面的「忘记密码」
・连登录ID也忘记了 → 登录页面的「忘记登录ID」
・还是登录不了 → 请联系我，我会马上重新发放

学习记录保存在服务器上。
换一台电脑或手机登录，也可以从上次的进度继续。
```
