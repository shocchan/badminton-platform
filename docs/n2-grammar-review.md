# N2文法180 取り込み監査＋人間レビュー成果物（Phase N2-B1）

> 原本: `無題のスプレッドシート.xlsx` シート「原：N2の文法180例文集」（**原本は改変していない**・読み取りのみ）。
> 生成物: `docs/n2-grammar-review.csv`（180行・レビュー用）／`src/lib/aiLesson/course/n2GrammarData.ts`（取り込みデータ）。
> **180項目を無検証で公開しない。** learner には `reviewStatus==='approved'` のみ表示（現状0）。

## 1. 原本の行数・列
- シート実寸: 201行 × 9列（A〜I）。ヘッダー1行＋**番号付き文法 180項目**（C列 no. 1〜180）＋装飾行。
- 列: A=単元 / B=頻出度 / C=no. / D=〜 / E=文法(expression) / F=メモ(意味) / G=例文 / H=例文2 / I=チェック。
- 原本の単元構成: **18単元 × 10項目**（行2,12,…,172）。

## 2. 正常取込数
- **180項目すべて取り込み**（件数一致・テストで担保 `courseN2Grammar.test.ts`）。
- 各項目に `grammarId(n2g-001..180) / no / sourceRow / sourceUnit / 例文 / 頻出度 / reviewStatus / reviewFlags` を付与。

## 3. 重複・類似候補
- **完全一致（正規化後）の重複表現: 0件。**
- 意味機能が近い項目（例: 逆接・譲歩系、原因結果系）は存在するが、**統合・削除は確定せず候補として人間レビューに委ねる**（勝手に統合しない）。

## 4. 表記修正候補 / 5. N2レベル確認候補
- E列は見出し表現（例: あげく／あまり／以上は／一方）で、`〜` 前置や送り仮名の表記統一が要確認。
- 一部に頻出度 `×`（4件）＝重要度低の印。N2範囲外・重複の可能性を人間確認。
- **原本に無い情報（読み方・中国語訳・接続・ニュアンス・類似差分・問題）は捏造せず未記入**。各項目に `needs_reading / needs_meaningZh / needs_connection / needs_nuance / needs_quiz` を付与。

## 6. 180項目の分類（監査サマリ）
| 状態 | 件数 | 内容 |
|---|---|---|
| 例文あり | **180** | 原本にG列例文が全項目に存在 |
| 原メモ(意味)あり | **10** | 残り170は意味未記入＝要作成 |
| 中国語訳あり | **0** | 全項目で `needs_meaningZh` |
| 読み方あり | **0** | 全項目で `needs_reading` |
| チェック済(I列) | 0 | — |
- **結論**: 原本は「**表現＋例文の一覧**」であり、教材（読み方・中国語訳・接続・問題）は未整備。**そのままでは学習公開不可**。会話/聴解/読解/試験の役割付与も人間レビューで行う。
