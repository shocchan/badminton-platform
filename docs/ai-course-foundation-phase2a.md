# しくみラボ Phase 2A（1単元縦切りMVP）
目的: 教材候補→人間レビュー→語彙→しくみ→小テスト→軸別結果→苦手抽出→復習候補の一連が成立するかを1単元で検証。
- 単元: 「自己紹介で使う基本のことば／自我介绍常用词与句型」（draft・語彙10=名詞6動詞3な形1・規則3・問題11=読3意3形接3使2）
- 学習軸: 読み/意味/形/接続/文中使用（合計点でなく軸別表示・満点でも完全習得と表示しない）
- 採点: 決定的（choice/かな正規化input/決定的シャッフルorder）・LLM不使用
- reviewStatus: 全data=draft固定。表示は adminOverrides.labPreview=true のテストアカウントのみ（一般・Andyさん非表示）
- 進捗: React stateのみ・「正式保存されません」を画面に明記。復習候補は純関数（誤答=翌日/ヒント正解=3日後/自力正解=なし）で導出のみ
