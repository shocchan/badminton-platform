# Premium学習ホームと3中核機能の世界観（Phase 2E-1 §18-§20・§24-§26）

作成: 2026-07-27。labPreview限定（一般受講生のホーム・ナビは不変）。

## 1. ホームHero（§18）

`CourseHome.tsx` の PlatformLearningMenu:
- 一目で分かる: 今日すること（決定的第一アクション: 復習期限→途中の文法→今日の会話→次の単元→今日の3語）・
  現在の目標・現在のパック（語数進捗つき）・所要時間・開始ボタン（**第一CTAは一つ**）。
- ビジュアル: 現在のパックカバー（実ファイルがある場合のみ）。PCは2カラム（テキスト＋カバー）、
  モバイルはテキスト優先でファーストビューのCTAを押し下げない。
- カバーは装飾でありalt空（学習情報を画像に依存させない・§32）。
- 語彙サマリーは `vocabHomeSummary.ts` の**動的import**（語彙データをメインbundleへ入れない・§31）。

## 2. AI会話の入口（§19）

監査結果: 旧ナビ（ホーム/ことば/しくみ/成長/設定）では中核のAI会話が
「ホームの中のカード」にしかなく、ことば・しくみと同格に見えなかった。

対応（案A改）: labPreviewナビを **ホーム / AI会話 / ことば / 日本語のしくみ / 成長 / 設定** の6項目に。
- モバイルは「日本語のしくみ」を短縮ラベル（しくみ/基础）にして6項目でも1行に収める。
- 「AI会話」タップ → ホームの会話開始カード（`#ai-course-conversation-entry`）へ直行
  （prefers-reduced-motion時はスクロールアニメなし）。会話開始UI自体はホームが正であり、
  二重画面を作らない。aria-currentはホーム表示中は home のまま（conversationは入口ショートカット）。
- ホームHero直下の学習メニュー先頭カードもAI会話（従来どおり）。
- 一般受講生のナビは変更なし。計測: `click_ai_course_conversation_nav`。

## 3. 3中核機能の世界観（§20）

共通: タイポグラフィ・角丸(rounded-2xl)・Depth（action-raised/card-interactive）・CTA形状・
余白・ページヘッダー・進捗表現（分離バー）。
個別: AI会話=青グラデ＋Mic（対話）／ことば=白＋teal＋BookOpen（見る・覚える）／
しくみ=indigo淡色＋PenLine（組み立てる）。全部を同じカードにしない。

## 4. 語彙ロードマップの旅表示（§24）

縦タイムライン（RoadmapStep・接続線＋ノード）:
目標 → 現在のパック（カバー・分離2バー）→ 知っていることばの確認（診断）→
毎日の学習（今日の3語）→ 問題で確認（3分復習）→ 定着の確認 → 次のパック。
- 次のパックは説明のみ・クリック不可。「準備中」バッジの乱発なし（N2注記は1箇所のみ）。
- ロックUIは使わない（done/activeのノード色のみ）。

## 5. 成長画面統合（§25）

labPreviewのみ `GrowthVocabCard`（動的import）:
学習を始めた語／読み・意味・使い方の確認語数（次元別）／定着確認済み／復習が必要。
「覚えたと思う」は自己評価として**別行**表示。「語彙力140」「N3達成率」等の断定スコアは出さない。
次アクション（今日の3語→3分復習）を優先表示。

## 6. 情報密度（§26）

- ホーム: Hero＋学習メニュー＋既存進捗（3ブロック以内）。
- ことばトップ: 現在のパック（1バー＋ロードマップリンク）・今日の3語（＋3分復習チップ）・カテゴリー。
  復習リスト・内訳詳細はトップから撤去（ロードマップ/成長画面へ。同じ進捗を重複表示しない）。
- 語彙詳細: 画像・語・中心意味・（展開で学習ポイント）・例文・自己評価・次へ。
- リッチ感は影・画像だけに依存させない: 余白・タイポ・一貫したdepthトークン・
  情報の絞り込みが主で、装飾は従。
