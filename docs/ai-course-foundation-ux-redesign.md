# しくみラボ UX再設計（2026-07-27 実施）

## 実機フィードバック（CEO・staging）
1. ラボ入口が見つけづらい／ホームの小カードに埋没 2. 5領域（今日/ことば/しくみ/復習/履歴）が同列で選択肢過多
3. 最初に開く場所が不明 4. 1画面の情報量過多 5. 記入式問題が学習開始の負担 6. 毎日気軽に続ける体験になっていない

## 再設計の目的
「しくみラボを、迷わず毎日使える学習体験へ」。AI会話（想起・発話・言い直し・実使用）と並ぶ
コースの中核機能として、しくみラボ＝認識・理解・選択・構造確認を担当する（役割分担・§22）。
結果画面・単元完了後に「次はAI会話で使ってみましょう」導線を将来追加できる構造（onExit/onGoReviewの
コールバック分離）を維持。会話ミッション本文・Realtime promptは不変。

## グローバルナビ
- デスクトップ: ホーム／成長／ロードマップ／**日本語のしくみ**／学習記録／設定（アイコン付き・aria-current）
- zh名は「日语基础」（直訳の実験室名を採用しない）。「試作」は小バッジでラボ内にのみ表示
- labPreview=trueのみDOM出力。モバイルはナビを折返し表示（横スクロール・極小文字・ハンバーガー埋没なし）。
  一般受講生（labなし5項目）は従来の表示のまま＝影響ゼロ

## 3領域構造（旧5領域→）
| 新 | 旧 | 内容 |
|---|---|---|
| 今日 | 今日 | 大カード1枚（状態から決定的に第一CTA一つ）＋進み具合＋単元導線の3ブロックのみ |
| 単元 | （今日の下部一覧） | 6単元の学習順カード（番号・名前・一言Can-do・時間・状態・CTA）＋補助導線 |
| 記録 | 復習＋履歴 | 復習候補→最近の単元→分野別の状態（展開式）→過去の結果（展開式）→リセット |

- **ことば・しくみ**（全語彙・全規則一覧）は削除せず、単元画面下部の「ことばから探す／しくみから探す」補助導線へ移動
- 最優先の復習は「今日」の第一CTAに自動表示（復習画面を探さなくても復習できる）

## 情報量制限（§14・1画面1目的）
- 今日: 主要ブロック3（大カード/進み具合/単元導線）・主要CTA1
- 単元開始: 単元名＋Can-do＋約N分・M問＋開始のみ。開始後に ことば→しくみ→問題→結果 を1ステップずつ（現在位置のみ強調）
- 問題: 一問一画面（単元名・進捗バー・問題・選択肢・あとで確認）
- 結果: 今日の結果＋正解数＋いちばん確認したいところ＋第一CTA1つ。分野別・復習時期は展開式。
  day1/errorTag等の技術用語は非表示（「明日もう一度確認しましょう」等の平易文言）

## 選択式問題方針
全問タップ式（詳細→ ai-course-foundation-question-interactions.md）。

## ja/zh 主要文言
今日/今天学习・単元/课程・記録/学习记录・今日の5分/今天学5分钟・続きから/继续学习・
復習を始める/开始复习・単元を選ぶ/选择课程・あとで確認/稍后确认

focus-visible・ドラッグ不要（すべてタップ）
