## 3. 新規生成が必要な画像（ChatGPTへそのまま送るプロンプト）

**スタイル共通指定（全プロンプトの末尾に必ず付ける）:**
> 温かみのある手描き風アニメイラスト。日本人女性の日本語教師「翔子先生」：30代前半、黒髪ボブ、黒縁メガネ、白いインナーに緑の襟元のテラコッタ（コーラルオレンジ）色カーディガン。優しく親しみやすい雰囲気。背景は無地のごく薄いクリーム色（切り抜きやすい単色・グラデーションなし）。上半身、正面〜やや斜め。縦横比3:4、高解像度。
> 【切り抜き用の必須条件】腕・手・指が最後まで完全に描かれていること／体が画像の端で切れない（四辺に余白を残す）／強い逆光・白いグロー・発光エフェクトを使わない／手と小物（湯のみ・マイク等）の輪郭が融合しない／文字・ロゴ・透かしを入れない。

| 優先 | slot | プロンプト本文（↑共通指定を続けて貼る） |
|---|---|---|
| P0 | `emptyReview` 専用 | 翔子先生が湯のみでお茶を飲みながらリラックスして微笑んでいるイラスト。湯のみと手の輪郭ははっきり分ける。「今日は休んでも大丈夫」という安心感のある表情。 |
| P0 | `error` | 翔子先生が少し困った表情で、申し訳なさそうに片手を軽く上げて謝っているイラスト。上げた手の指5本まで完全に描く。深刻すぎず、「大丈夫、もう一度やってみましょう」と伝わる柔らかい雰囲気。 |
| P0 | `complete` 強化版 | 翔子先生が両手でハイタッチを求めている正面イラスト。両手のひらと指を完全に描く。満面の笑顔で「よくできました！」の瞬間。 |
| P1 | `growth` | 翔子先生が双眼鏡を両手で持って遠くを見ながらワクワクしているイラスト。双眼鏡と手の輪郭を分ける。成長の旅を一緒に楽しむ探検のイメージ。 |

| P1 | マイク許可 | 翔子先生が小さなマイクを片手で軽く指し示して「話してみましょう」と促すイラスト。マイクと手の輪郭を分ける。 |

| P2 | 初回オンボーディング | 翔子先生が軽くおじぎをして迎えているイラスト。両腕は体の前で自然に。 |

**推奨サイズ・比率**: 生成は 1024×1365px（3:4）以上 → U²-Netで透過 → WebP化（幅520px前後・quality82）。既存パイプライン（`scratchpad/rematte_all_u2net.py` 相当）を流用。**逆光・強いグローの背景は指定しない**（切り抜き破綻の教訓）。

## 4. 実装コンポーネント
`src/components/ai-course/CourseIllustration.tsx`
- `slot` → 画像・altの対応を `SLOT_MAP` に集約（null = 描画しない＝画像なしでも完成）
- `decorative` で装飾用途は `alt=""`＋`aria-hidden`
- `loading="lazy"` `decoding="async"`、幅指定でCLSなし

## 5. アニメーション方針
**使う（すべて motion-safe: prefers-reduced-motion では無効）:**
- イラスト登場: `report-in`（fade＋わずかな上昇・0.5s）— 既存keyframes流用
- 完了チェック: `check-pop`（既存）
- 接続待ちアバター: `voice-breathe`（既存・ゆっくり呼吸）
- アコーディオン開閉・CTA hover/active（既存Tailwind transition）

**使わない:**
- 会話中の常時ループアニメ・パララックス・点滅・キャラクター移動
- 3秒を超えるアニメーション、読解を妨げる動き

## 6. パフォーマンス影響
- 新規JSなし（コンポーネント約1KB）。画像は全て既存WebP（48〜60KB）を再利用・lazy
- 会話中は画像追加なし＝Realtime帯域へ影響なし
